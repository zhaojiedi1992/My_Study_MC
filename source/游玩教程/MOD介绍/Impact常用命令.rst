区域操作命令
==================================================

选择区域
--------------------------------------------------

- **选择第一个点**：
  ```
  #sel 1
  ```
  站在你想要的第一个位置，执行此命令。

- **选择第二个点**：
  ```
  #sel 2
  ```
  站在你想要的第二个位置，执行此命令。

区域填充
--------------------------------------------------

- **填充指定方块**：
  ```
  #sel set <方块ID>
  ```
  例如，将选择区域全部填充为泥土：
  ```
  #sel set dirt
  ```

- **替换方块**：
  ```
  #sel replace <原方块ID> <新方块ID>
  ```
  例如，将选择区域内的空气替换为泥土：
  ```
  #sel replace air dirt
  ```

- **清除区域**：
  ```
  #sel clear
  ```
  清除选择区域内的所有方块。

命令使用注意事项
==================================================

1. **命令格式**：所有命令都以 `#` 开头，后面跟命令名称和参数。

2. **方块ID**：使用Minecraft的方块ID，例如 `dirt`、`stone`、`diamond_ore` 等。

3. **坐标系统**：使用Minecraft的三维坐标系统（X, Y, Z）。

4. **权限**：某些命令可能需要服务器权限才能使用。

5. **版本兼容性**：不同版本的Impact可能有不同的命令，使用前请确认命令是否可用。

6. **服务器规则**：在使用这些命令前，请确保遵守服务器的规则，不要使用可能被视为作弊的功能。

7. **性能影响**：某些命令（如X-Ray、ESP）可能会影响游戏性能，根据电脑配置谨慎使用。
