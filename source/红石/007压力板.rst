什么是压力板？
==================================================

压力板是一种可以被踩压激活的红石元件，就像是游戏里的地板开关。当你或其他东西踩上去时，它会激活并产生红石信号。

压力板的充能特性
==================================================

压力板激活时的充能情况很特别：

- **强充能**：压力板会强充能自己本身和下方附着的方块（但必须是非透明方块）
- **不会强充能上方**：压力板不会强充能上方的方块
- **弱充能/直接激活**：压力板可以向上方的红石元件（比如红石粉、红石灯）输出信号，但这不是强充能，而是弱充能或直接激活

简单来说：
- 踩压力板 → 压力板本身变亮 → 下方方块变亮 → 上方的红石粉或红石灯变亮
- 但上方的普通方块不会变亮（不会被强充能）

压力板的工作原理
==================================================

1. **未激活状态**：压力板平放在方块上，没有红石信号
2. **激活状态**：有东西踩上去时，压力板会下沉一点，同时产生红石信号
3. **信号传递**：信号会传递给下方的方块和周围的红石元件
4. **恢复状态**：东西离开后，压力板会弹回原位，信号消失

压力板的应用
==================================================

压力板在 Minecraft 中有很多酷炫的用处：

1. **自动门**：踩上压力板，门自动打开，离开后门自动关闭
2. **陷阱**：敌人踩上压力板，陷阱自动触发
3. **灯光系统**：走进房间踩上压力板，灯自动亮起
4. **物品检测**：用铁质压力板检测箱子里是否有物品掉出来
5. **生物检测**：用木质压力板检测是否有动物走进农场
6. **密码门**：用多个压力板组合成密码，按对顺序才能开门

**木质压力板**
- 材料：2个木板
- 制作方法：在工作台的同一行放2个木板

**石质压力板**

- 制作方法：在工作台的同一行放2个石头

**铁质压力板**

- 制作方法：在工作台的同一行放2个铁锭

**金质压力板**
- 材料：2个金锭
- 制作方法：在工作台的同一行放2个金锭

**测重压力板**
- 材料：2个测重压力板（仅在某些版本可用）
- 制作方法：在工作台的同一行放2个测重压力板

压力板的信号特性详解
==================================================

**信号强度**
- 木质、石质、金质压力板：固定15级信号（最强）
- 铁质压力板：根据物品数量，1-15级信号
  - 1个物品：1级信号
  - 64个物品：15级信号
- 测重压力板：根据生物大小，1-15级信号
  - 小动物（如鸡、兔子）：1-5级信号
  - 中型生物（如羊、猪）：6-10级信号
  - 大型生物（如牛、玩家）：11-15级信号

**信号持续时间**
- 只要有触发物在上面，压力板就会持续产生信号
- 触发物离开后，信号立即消失
- 没有延迟效果

**信号传递范围**
- 压力板可以激活下方的方块
- 可以激活周围1格内的红石元件
- 可以直接激活上方的红石线和红石灯

与其他红石元件的配合使用
==================================================

**与门配合**
- 用多个压力板组成与门
- 必须同时踩多个压力板才能触发
- 可以制作需要多人合作的装置

**与中继器配合**
- 用中继器延长压力板的信号传递距离
- 可以制作延时效果
- 适合长距离控制

**与比较器配合**
- 用比较器检测铁质压力板的信号强度
- 可以制作精确的物品数量检测系统
- 适合自动分类机

**与活塞配合**
- 用压力板控制活塞的伸缩
- 可以制作自动门、陷阱
- 适合隐藏装置

详细应用案例
==================================================

**案例1：多人合作门**
1. 在门的两侧各放一个压力板
2. 两个压力板连接到一个与门
3. 只有两个人同时踩压力板，门才会打开

**案例2：物品分类系统**
1. 在漏斗下方放铁质压力板
2. 用比较器检测压力板的信号强度
3. 根据信号强度控制不同的活塞门
4. 实现自动分类不同数量的物品

**案例3：生物检测陷阱**
1. 在必经之路上放测重压力板
2. 用比较器检测压力板的信号强度
3. 只有大型生物（如玩家）通过时才触发陷阱
4. 防止小动物误触发

**案例4：隐藏的秘密房间**
1. 在地毯下放木质压力板
2. 压力板连接到活塞门
3. 踩上压力板，墙壁上的活塞门打开
4. 进入后，门自动关闭

压力板的优缺点分析
==================================================

**优点：**
- 制作简单，材料易得
- 操作直观，踩上去即可触发
- 不需要手动开关
- 可以检测生物和物品
- 信号强度稳定

**缺点：**
- 只能检测是否有触发物，不能区分触发物类型
- 没有延时功能
- 铁质压力板的信号强度计算较复杂
- 容易被误触发（尤其是木质压力板）
- 不能远程控制

**适用场景：**
- 自动门系统
- 陷阱触发
- 物品检测
- 生物计数
- 秘密入口
