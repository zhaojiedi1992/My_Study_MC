竹子农场
================================

竹子农场能够自动种植和收割竹子，是生存初期获取竹子的重要设施。

原理说明
==================================================
利用观察者检测竹子生长，通过活塞自动收割，水流收集系统将竹子集中存储。

**核心机制**
- 竹子在水边快速生长
- 观察者检测竹子高度
- 活塞推动收割竹子
- 水流收集掉落物品

材料需求
==================================================
- 竹子 x若干（初始种植）
- 观察者 x1-4
- 活塞 x1-4
- 红石粉 x若干
- 水桶 x1-2
- 漏斗 x1-4
- 箱子 x1-2
- 建筑方块若干

竹子获取
==================================================

**寻找竹子**
- 竹子生成于丛林生物群系
- 在竹林中大量生成
- 可在沉船箱子中找到

**种植条件**
- 种植在泥土、草方块、沙子等上
- 需要水源在旁边
- 生长高度可达12-16格

基础竹子农场建造
==================================================

**建造步骤**

1. **选择位置**
   - 平坦开阔的区域
   - 靠近基地便于收集
   - 确保有足够空间

2. **搭建种植平台**
   - 放置水源
   - 在水源旁种植竹子
   - 确保竹子有生长空间

3. **安装检测系统**
   - 在竹子预期高度放置观察者
   - 观察者面向竹子
   - 连接红石电路

4. **建造收割系统**
   - 在观察者下方放置活塞
   - 活塞推动时收割竹子
   - 确保收割高度合适

5. **设置收集系统**
   - 在底部建造水流收集
   - 漏斗连接箱子
   - 确保物品不丢失

高效竹子农场设计
==================================================

**单核设计**
- 产量：约200-400竹子/小时
- 特点：结构简单，易于建造
- 适合：生存初期

**多核设计（4-8核）**
- 产量：约800-1600竹子/小时
- 特点：效率更高，需要更多材料
- 适合：中期发展

**关键优化**
- 调整观察者高度（建议12-14格）
- 使用红石时钟优化收割频率
- 增加种植数量

竹子用途
==================================================

**主要用途**
- 制作竹筏（运输）
- 制作脚手架（建筑）
- 制作木棍（合成材料）
- 熔炉燃料
- 熊猫食物

**脚手架特性**
- 可堆叠放置
- 方便攀爬
- 用于高空建筑

常见问题
==================================================

**竹子不生长**
- 确保有水源
- 检查光照条件
- 等待足够时间

**收割效率低**
- 调整观察者高度
- 优化活塞位置
- 检查红石电路

**收集不完整**
- 优化水流系统
- 增加漏斗数量
- 检查是否有卡住

维护建议
==================================================
- 定期检查观察者和活塞
- 清理收集系统
- 补充竹子种植
- 备用材料存放在附近

扩展升级
==================================================

**与熔炉组联动**
- 竹子作为燃料
- 自动供给熔炉
- 实现燃料自给自足

**与合成系统联动**
- 自动合成木棍
- 制作脚手架
- 建造自动化生产线
