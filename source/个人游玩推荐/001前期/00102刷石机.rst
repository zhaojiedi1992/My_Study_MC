刷石机
================================

刷石机是生存初期最重要的基础设施之一，能够自动生成并收集石头和圆石。

原理说明
==================================================
利用水流和岩浆接触生成圆石或石头，通过活塞推动实现自动采集。

**生成类型**
- **圆石生成器**：水流先接触岩浆源，生成圆石
- **石头生成器**：岩浆先接触水流，生成石头（更高效）

材料需求
==================================================
- 活塞 x4-8
- 红石粉 x16
- 红石火把 x4
- 红石中继器 x4
- 水桶 x1
- 岩浆桶 x1
- 漏斗 x1-4
- 箱子 x1-2
- 建筑方块若干

基础刷石机建造
==================================================

**建造步骤**

1. **搭建框架**
   - 建造5x3的基础平台
   - 在平台中央留出2格空间用于生成石头

2. **放置流体**
   - 在左侧放置水流（从上往下流）
   - 在右侧放置岩浆源
   - 确保岩浆先接触水流

3. **安装活塞系统**
   - 在石头生成位置前方放置活塞
   - 连接红石电路和时钟电路
   - 调整中继器延迟（建议2-4刻）

4. **设置收集系统**
   - 在活塞推动方向放置漏斗
   - 连接箱子存储

高效刷石机设计
==================================================

**2x2双核设计**
- 产量：约600-800石头/小时
- 特点：结构简单，适合初期建造

**3x3四核设计**
- 产量：约1200-1600石头/小时
- 特点：效率更高，需要更多材料

**关键优化点**
- 使用红石时钟自动触发活塞
- 调整活塞推动频率匹配生成速度
- 使用漏斗矿车提高收集效率

自动化扩展
==================================================

**与熔炉组联动**
- 将圆石直接输入熔炉组
- 自动烧炼成平滑石头
- 配合燃料自动供给系统

**与合成器联动**
- 自动合成石砖、台阶等
- 配合自动分类存储系统

常见问题
==================================================

**石头不生成**
- 检查水流和岩浆位置是否正确
- 确保岩浆源完整（不是流动的岩浆）

**活塞不工作**
- 检查红石电路连接
- 调整时钟电路频率

**收集效率低**
- 增加漏斗数量
- 使用漏斗矿车替代普通漏斗

维护建议
==================================================
- 定期检查岩浆源是否耗尽
- 清理收集系统防止堵塞
- 备用岩浆桶存放在附近
