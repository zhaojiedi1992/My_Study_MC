树场
================================

全自动树场能够自动种植、生长、砍伐和收集木材，是生存初期重要的资源生产设施。

原理说明
==================================================
利用活塞和红石电路实现树木的自动种植和砍伐，通过水流收集系统将木材集中到存储箱。

**核心机制**
- 活塞推动破坏树木方块
- 骨粉加速树苗生长
- 水流收集掉落物品
- 漏斗系统自动存储

材料需求
==================================================
- 活塞 x16-32
- 粘性活塞 x8-16
- 红石粉 x64
- 红石火把 x16
- 红石中继器 x16
- 观察者 x8-16
- 水桶 x4-8
- 漏斗 x8-16
- 箱子 x4-8
- 树苗若干
- 骨粉若干
- 建筑方块若干

树种选择
==================================================

**橡木**
- 生长速度：中等
- 特点：用途广泛，可掉落苹果
- 推荐度：★★★★★

**白桦木**
- 生长速度：快
- 特点：颜色美观，生长稳定
- 推荐度：★★★★☆

**云杉木**
- 生长速度：中等
- 特点：可长成大树，产量高
- 推荐度：★★★☆☆

**丛林木**
- 生长速度：慢
- 特点：可长成巨型树，可可豆附着
- 推荐度：★★☆☆☆

基础树场建造
==================================================

**建造步骤**

1. **选择位置**
   - 平坦开阔的区域
   - 靠近基地便于收集
   - 确保有足够空间（建议16x16以上）

2. **搭建种植平台**
   - 建造2x2种植区域
   - 放置泥土或草方块
   - 种植树苗

3. **建造砍伐系统**
   - 在树木预期高度安装活塞阵列
   - 使用观察者检测树木生长
   - 连接红石电路控制活塞

4. **安装骨粉系统**
   - 使用发射器自动施放骨粉
   - 连接到骨粉存储箱
   - 设置自动补充机制

5. **建造水流收集**
   - 在底部建造水流渠道
   - 确保水流覆盖所有掉落区域
   - 引导物品到收集点

6. **设置存储系统**
   - 安装漏斗链连接箱子
   - 可选：添加自动分类系统

高效树场设计
==================================================

**单核设计（2x2）**
- 产量：约600-800原木/小时
- 特点：结构简单，材料需求低
- 适合：生存初期

**四核设计（4个2x2）**
- 产量：约2000-3000原木/小时
- 特点：效率高，需要更多材料
- 适合：中期发展

**关键优化**
- 使用T触发器实现自动循环
- 调整骨粉使用量（每棵树6-8个骨粉）
- 优化活塞推动顺序
- 使用漏斗矿车提高收集效率

自动化扩展
==================================================

**与熔炉组联动**
- 原木自动烧炼成木炭
- 木炭作为燃料循环使用

**与合成系统联动**
- 自动合成木板、木棍
- 制作工具、火把等

**与树苗循环联动**
- 掉落的树苗自动重新种植
- 实现完全自动化

常见问题
==================================================

**树木不长**
- 检查光照等级（需要9以上）
- 确保有足够空间（上方5格以上）
- 骨粉是否正常施放

**活塞无法破坏树木**
- 检查活塞数量是否足够
- 调整红石信号延迟
- 确保活塞同时触发

**物品收集不完整**
- 扩大水流覆盖范围
- 增加漏斗数量
- 检查是否有物品卡住

维护建议
==================================================
- 定期补充骨粉和树苗
- 检查活塞系统是否正常
- 清理收集系统
- 备用材料存放在附近
