丐版村民交易所
================================

丐版村民交易所是生存初期获取廉价交易的重要设施，通过僵尸治疗获得打折村民。

原理说明
==================================================
利用僵尸感染村民再治愈的机制，使村民交易价格大幅降低，实现低成本资源获取。

**核心机制**
- 僵尸感染村民
- 金苹果+虚弱药水治愈
- 治愈后交易价格降低
- 多次治愈可叠加折扣

材料需求
==================================================
- 村民若干
- 僵尸刷怪蛋或自然生成的僵尸
- 金苹果 x若干
- 虚弱药水 x若干
- 喷溅型虚弱药水 x若干
- 方块若干（建造隔离间）
- 告示牌若干
- 床 x若干
- 各种工作站

基础交易所建造
==================================================

**建造步骤**

1. **建造村民隔离间**
   - 建造1x2的隔离空间
   - 确保村民无法逃脱
   - 预留僵尸进入通道

2. **准备感染区域**
   - 在隔离间旁建造僵尸等候区
   - 确保僵尸能看到村民
   - 设置门或活板门控制僵尸进出

3. **设置治愈设施**
   - 准备金苹果和虚弱药水
   - 设置快捷使用栏位
   - 确保治愈过程安全

4. **安装工作站**
   - 根据需要放置对应工作站
   - 确保村民能锁定职业
   - 常见工作站：讲台、高炉、锻造台等

感染与治愈流程
==================================================

**感染流程**
1. 将村民推入隔离间
2. 释放僵尸进入隔离间
3. 等待僵尸感染村民（约30秒-2分钟）
4. 感染后村民变成僵尸村民

**治愈流程**
1. 对僵尸村民使用喷溅型虚弱药水
2. 喂食金苹果
3. 等待治愈（约2-5分钟）
4. 治愈后村民价格降低

**折扣效果**
- 第一次治愈：价格降低约50%
- 多次治愈：可叠加折扣
- 最低可达1个绿宝石换大量物品

职业锁定技巧
==================================================

**锁定方法**
1. 村民获得职业后立即交易一次
2. 交易后职业将被锁定
3. 即使破坏工作站也不会改变职业

**注意事项**
- 治愈前不要交易
- 治愈后再锁定职业
- 确保工作站类型正确

常见问题
==================================================

**僵尸不感染村民**
- 确保难度不是和平模式
- 检查僵尸是否能接触村民
- 等待更长时间

**治愈失败**
- 确保使用了虚弱药水
- 检查金苹果是否正确喂食
- 等待足够时间

**价格没有降低**
- 确保治愈流程正确
- 尝试多次治愈
- 检查是否已经交易过

维护建议
==================================================
- 储备足够的金苹果和虚弱药水
- 定期检查村民状态
- 记录每个村民的职业和交易
- 建造多个隔离间提高效率

扩展升级
==================================================

**自动化升级**
- 添加自动感染系统
- 使用发射器自动投掷药水
- 建造村民分类系统

**交易大厅扩展**
- 按职业分类排列村民
- 添加快速传送系统
- 建造存储和补给区
