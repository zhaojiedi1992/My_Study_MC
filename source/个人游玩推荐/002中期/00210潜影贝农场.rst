潜影贝农场
================================

潜影贝农场是末地获取潜影壳的重要设施。

原理说明
==================================================
利用末地城中潜影贝的生成机制，自动击杀潜影贝获取潜影壳。

**核心机制**
- 潜影贝在末地城生成
- 潜影贝掉落潜影壳
- 潜影壳用于制作潜影盒

材料需求
==================================================
- 建筑方块若干
- 漏斗 x8-16
- 箱子 x4-8
- 活塞 x若干
- 建筑方块若干

选址要求
==================================================

**最佳位置**
- 末地城内部
- 末地船附近
- 远离其他危险区域

潜影贝农场建造
==================================================

**建造步骤**

1. **定位末地城**
   - 通过末地折跃门
   - 寻找末地城
   - 清理周围潜影贝

2. **搭建刷怪平台**
   - 在末地城内建造平台
   - 确保潜影贝生成
   - 使用半砖减少其他怪物

3. **建造引导系统**
   - 设计引导通道
   - 将潜影贝集中到击杀区
   - 确保引导效率

4. **设置击杀系统**
   - 建造击杀平台
   - 设计安全击杀方式
   - 收集掉落物

潜影壳用途
==================================================

**主要用途**
- 制作潜影盒
- 潜影盒可存储物品
- 潜影盒可保留物品

常见问题
==================================================

**潜影贝不生成**
- 检查末地城位置
- 确保生成条件
- 调整平台设计

维护建议
==================================================
- 定期检查平台
- 清理收集系统
- 准备足够的装备
