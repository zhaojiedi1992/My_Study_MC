守卫者农场
================================

守卫者农场是自动生产海晶碎片、海晶砂粒和海绵的高级设施，是大后期的重要海洋资源来源。

原理说明
==================================================
利用海底神殿中守卫者的生成机制，通过自动化系统实现海洋资源的批量生产。

**核心机制**
- 守卫者在海底神殿生成
- 使用水流引导和自动击杀
- 自动收集掉落物

材料需求
==================================================
- 建筑方块若干（建议使用海晶灯）
- 水桶 x64-128
- 岩浆桶 x若干
- 漏斗 x32-64
- 箱子 x16-32
- 活塞 x若干
- 红石粉 x若干
- 脚手架 x若干

海底神殿寻找
==================================================

**寻找方法**
- 使用海洋探险家地图
- 探索深海生物群系
- 使用F3调试界面查看

**准备工作**
- 水下呼吸药水
- 夜视药水
- 钻石装备
- 足够的食物

守卫者农场建造
==================================================

**建造步骤**

1. **清理海底神殿**
   - 击杀所有远古守卫者
   - 清除神殿内的守卫者
   - 标记重要结构

2. **建造生成平台**
   - 在神殿周围建造平台
   - 使用半砖减少其他怪物生成
   - 确保守卫者生成区域黑暗

3. **安装水流系统**
   - 建造水流引导通道
   - 将守卫者引导到击杀区
   - 确保水流覆盖整个神殿

4. **设置击杀系统**
   - 使用岩浆或玩家击杀
   - 设计高效击杀机制
   - 确保守卫者被快速击杀

5. **安装收集系统**
   - 安装漏斗收集掉落物
   - 连接到存储箱子
   - 可选：添加经验收集

掉落物与用途
==================================================

**主要掉落**
- 海晶碎片：制作海晶灯
- 海晶砂粒：制作海晶灯
- 海绵：吸水工具
- 生鳕鱼：食物
- 经验球：附魔用

**海晶灯制作**
- 4海晶碎片 + 5海晶砂粒
- 亮度15，水下可用
- 美观的光源方块

**海绵用途**
- 吸干水源
- 建造水下建筑
- 清理大型水域

常见问题
==================================================

**守卫者不生成**
- 确保玩家在128格内
- 检查是否清除了远古守卫者
- 确保生成区域黑暗

**收集效率低**
- 优化水流系统
- 增加漏斗数量
- 使用漏斗矿车

维护建议
==================================================
- 定期检查水流系统
- 清理收集系统
- 确保击杀系统正常
