Xaero's Minimap 与 Xaero's World Map
====================================

本页介绍当前整合包中的两个 Xaero 地图 MOD：Xaero's Minimap 26.4.0 与 Xaero's World Map 1.44.0。

版本信息以整合包 MOD 清单为准。实际安装时，还需要根据自己的 Minecraft 版本、加载器和项目发布页核对兼容性。

一句话概括
------------

Xaero's Minimap 负责“看清眼前”，Xaero's World Map 负责“看懂整个世界”。两者可以联动路径点：近处用小地图导航，远处用全屏地图规划路线。

Xaero's Minimap：把方向感放在屏幕角落
--------------------------------------

Xaero's Minimap 是一个实时小地图 MOD。它显示玩家周边的地形轮廓和方向信息，让玩家在移动、探洞或寻找目标时，不必频繁打开全屏地图确认自己朝哪边走。

主要功能
~~~~~~~~

* **接近原版风格的小地图**：放在 HUD 角落，信息集中但不抢画面主体。
* **方向显示**：帮助判断当前朝向，减少“转了一圈又回到原地”的情况。
* **路径点**：给家、村庄、传送门或农场等地点留下标记，便于之后返回。
* **周边地形导航**：快速观察附近的地形变化和已走过的路线。

适合的场景
~~~~~~~~~~

* 生存前期找村庄、找洞穴或回家。
* 长距离探索时确认方向。
* 在基地、农场和传送门之间往返。
* 不想一直打开全屏地图、希望保留更多实机视野时。

Xaero's World Map：从局部视野切换到全局规划
--------------------------------------------

Xaero's World Map 是全屏世界地图 MOD。随着玩家探索，地图会逐步记录已经走过的地形；打开世界地图后，可以从更大的尺度查看路线、区域和已探索范围。

主要功能
~~~~~~~~

* **自动记录探索地形**：走过的区域会逐步补充到世界地图中。
* **全屏地图视图**：适合查看大范围地形和规划远行路线。
* **缩放与拖动浏览**：可以在局部细节和整体路线之间切换。
* **路径点联动**：与 Xaero's Minimap 配合时，同一组地点标记可以用于近距离导航和远距离规划。

适合的场景
~~~~~~~~~~

* 规划跨区域远行路线。
* 回看已经探索过的区域。
* 整理多个基地、村庄、结构或资源点的位置。
* 在地图上先确定大方向，再回到游戏内用小地图完成最后一段路。

两个 MOD 怎么配合
------------------

.. list-table::
   :header-rows: 1
   :widths: 34 28 38

   * - 需求
     - 更适合使用
     - 原因
   * - 看当前朝向和身边地形
     - Xaero's Minimap
     - 信息常驻 HUD，抬眼即可查看。
   * - 规划跨区域路线
     - Xaero's World Map
     - 全屏视野更大，适合看整体布局。
   * - 记住一个地点
     - 路径点功能
     - 给目标留下可复用的导航标记。
   * - 远处找方向、近处不迷路
     - 两者一起使用
     - 世界地图规划，小地图执行。

可以把它们理解成两种尺度的地图：

.. code-block:: text

   World Map：先看全局，决定“往哪里走”
                     ↓
   Minimap：回到现场，确认“现在朝哪走”
                     ↓
   Waypoint：把家、村庄、传送门等地点记下来

安装与使用提醒
--------------

#. **先核对版本**：Minecraft 版本、加载器和 MOD 版本需要相互匹配。这里介绍的是清单中的 Xaero's Minimap 26.4.0 与 Xaero's World Map 1.44.0。
#. **按需安装**：只想要 HUD 小地图时，可以先安装 Minimap；需要查看大范围探索记录和规划路线时，再加入 World Map。
#. **进入世界后检查按键**：首次使用建议打开按键设置，确认小地图、世界地图和路径点相关快捷键没有冲突。
#. **记住探索边界**：世界地图记录的是已经探索过的区域；没有走到的地方不会因为安装 MOD 就自动变成已探索地图。
#. **注意客户端定位**：这类 MOD 主要改善客户端的导航与信息查看体验，不会替代服务器本身的地图、权限或传送功能。

B 站视频开场文案（短版）
------------------------

   下矿、远行、找回家的路，原版没有小地图时，迷路往往只差一个转身。Xaero's Minimap 26.4.0 把方向、周边地形和路径点放到屏幕角落；Xaero's World Map 1.44.0 再把探索过的世界铺成一张全屏地图。一个负责看眼前，一个负责看全局，两者联动后，找路和记地点都会轻松很多。

B 站简介文案（基础版）
----------------------

   这期介绍两个实用的 Minecraft 导航 MOD：Xaero's Minimap 26.4.0 与 Xaero's World Map 1.44.0。

   Xaero's Minimap 提供接近原版风格的小地图、方向显示、路径点和周边地形导航；Xaero's World Map 会自动记录探索过的地形，并提供可缩放的全屏世界地图。两者可以联动路径点：用世界地图规划大范围路线，再用小地图完成近距离导航。

   安装前请根据自己的 Minecraft 版本和加载器核对兼容性，进入游戏后也建议检查按键绑定。世界地图只会记录实际探索过的区域，未探索地形不会自动生成。

   Modrinth：

   * `Xaero's Minimap <https://modrinth.com/mod/xaeros-minimap>`_
   * `Xaero's World Map <https://modrinth.com/mod/xaeros-world-map>`_
