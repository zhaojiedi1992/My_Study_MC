Gamma 亮度

Quick start

快速上手

先把常用功能放到顺手的位置，再逐项验证。

  1. X + C 打开 Tweakeroo 配置
  2. 搜索功能名称并设置开关
  3. 绑定快捷键，按实际需要微调参数

先在单人世界验证按键是否冲突。

一次只启用一个新功能，问题更容易定位。
