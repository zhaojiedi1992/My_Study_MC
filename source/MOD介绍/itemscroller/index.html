🖱️ 核心操作一：滚轮移物

鼠标悬停在格子上，滚动滚轮！

操作效果图示
直接滚动移动 1 个📦 → 1个
Shift + 滚动移动整堆📦 → 64个
Alt + 滚动移动所有同类📦📦📦 → 全部
Alt+Shift + 滚动移动所有物品🗃️ → 清空
💡 小技巧：往背包方向滚 = 收进来，往容器方向滚 = 放进去！

🖱️ 核心操作二：拖拽批量操作

按住快捷键 + 拖拽鼠标，路径上的格子全部处理！

快捷键 + 操作效果
Ctrl + 左键拖拽每格移走 1 个
Shift + 左键拖拽每格整堆移走
Alt + 左键拖拽每格所有同类移走
Q + 左键拖拽批量丢弃物品
🚀 拖过去就完事了！

🗑️ 批量丢弃技巧

Q + 左键拖拽 = 丢弃高手

  • 🧹 整理背包时快速清理垃圾物品
  • 🖱️ 一次拖拽丢掉所有不需要的物品
  • ⚡ 比一个一个按 Q 快 100 倍！

📋 配方系统：存储配方

最多存储 144 个配方，永远不忘怎么合成！

  1. 打开合成台
  2. 摆好所需配方
  3. 按 A 键 → 显示配方面板
  4. 保存配方，永久留存！
  • 📌 配方按名称分类管理
  • 🔍 支持快速搜索配方
  • ♾️ 144 个配方存储上限
🔑 A 键 = 配方面板开关
