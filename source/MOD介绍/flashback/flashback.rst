Flashback：录制回放，再用时间轴制作镜头
==============================================

Flashback 是客户端回放与镜头制作 MOD。它保存的是可重新播放、可编辑的回放数据，而不是把屏幕直接录成视频：先在游戏中录制，再在回放里用自由相机、时间轴和关键帧编排镜头，最后导出视频或图片。

本文按上游 ``0.41.1`` 的 Minecraft 26.2 源码基线整理：提交 a612fea（2026-06-25）。当前 HSDS 26.2 整合包的 23 个已核对功能 MOD 中尚未发现 Flashback JAR；以下是可选扩展的功能说明，安装前请再确认实际版本与依赖。

现有完整操作手册位于 ``source/extra/MOD介绍/flashback/Flashback-功能列表与操作手册.md`` ，本页将其归纳为可快速查阅的正式文档。

它能做什么
------------

.. list-table::
   :header-rows: 1
   :widths: 20 80

   * - 功能组
     - 源码确认的能力
   * - 录制与标记
     - 开始、暂停、恢复、完成、取消录制；可自动开始/完成，异常退出后尝试恢复未完成录制。支持四组可配置标记键，也可用 ``/flashback mark`` 写入颜色、说明、位置和维度。
   * - 回放管理
     - 主菜单打开回放；按名称、日期、世界、时长或文件大小搜索/排序；重命名、删除、从外部 ``.zip`` 文件打开，并可将两段兼容回放首尾合并。
   * - 时间轴编辑
     - 播放、跳转、缩放、导出入点/出点、场景、轨道、批量选择、复制粘贴、撤销/重做。一个回放可保留多个不同剪辑方案。
   * - 镜头与时间
     - 自由相机、相机路径、环绕、实体追踪、镜头抖动、FOV、回放速度、延时、一天中的时间、冻结和外部音频轨。
   * - 视觉与实体
     - 分别控制 HUD、方块、实体、玩家、粒子、天空、迷雾、天气、夜视及渲染过滤；可在回放中旁观、跟随、隐藏、改名、换皮肤或强制高亮实体。
   * - 导出
     - 视频、截图、PNG 序列与导出队列；可调分辨率、帧率、投影、码率、编码器、游戏声音、SSAA 和透明天空。

时间轴关键帧
--------------

``Flashback.java`` 实际注册了下列面向普通编辑界面的十类关键帧：

* **相机**：位置、朝向、滚转，适合直线或曲线运镜。
* **相机环绕**：围绕中心点、距离和角度运动，适合展示建筑或人物。
* **追踪实体**：跟随实体的头、身体或脚，并可添加位置/视角偏移。
* **相机抖动与 FOV**：制造冲击感、推拉感或远近景变化。
* **速度、延时、时间、冻结**：控制回放快慢、延时压缩、日夜和定格。
* **音频轨**：将外部音频放到指定时间点作播放参考或导出素材。

关键帧之间可选平滑、线性、缓入、缓出、缓入/缓出、保持与 Hermite 插值。源码还注册了“方块覆盖”类型，但 ``0.41.1`` 不允许从普通时间轴创建它，因此不应把它当成常规可用关键帧宣传。

推荐工作流
------------

1. 进入单人世界或服务器后，从暂停菜单开始录制；想保留的事件随手打标记。
2. 完成录制后回到主菜单，打开回放并先确认版本、模组与资源包警告。
3. 在时间轴设置入点和出点，新建“相机”轨道，在起点和终点放置镜头关键帧。
4. 用自由相机检查路径，再添加 FOV、追踪、速度或天气等关键帧。
5. 在视觉页隐藏不需要的界面或实体，最后以低分辨率短片试导出一次。
6. 确认构图、声音和编码器正常后，再按目标分辨率加入导出队列。

录制、声音与多人边界
------------------------

* “完成录制”会保存；“取消录制”会删除本次临时录制，二者不要混淆。
* 若要录制 Simple Voice Chat，必须在录制**之前**启用相关选项；没有录到的语音无法事后补回。录制他人语音前也应先征得同意。
* 多人服务器中，回放只能记录客户端实际接收到的区块、实体和数据。它不是全服监控工具，也不能绕过服务器的可见性或权限限制。
* 高帧率第一人称位置记录、Bobby 区块缓存和语音录制都会增加文件体积或资源开销；按成片需求开启即可。

安装要求
----------

``0.41.1`` 的上游构建声明 Minecraft ``>26.1 <26.3`` 、Java 21+、Fabric Loader 0.15.10+ 与 Fabric API 0.107.0+。其环境为 ``client`` ，服务器通常不需要安装。它还声明了 Mod Menu、Simple Voice Chat 和 Frex 的兼容入口；使用 Iris 时应避免低于 ``1.10.9`` 的版本。

应从发布页选择与实际 Minecraft 版本相匹配的 Flashback 和 Fabric API 文件，不能只按 MOD 版本号混装旧构建。
