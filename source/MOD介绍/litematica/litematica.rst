Litematica - 从创建投影到协作建造
========================================

Litematica 是一款用于 Minecraft 建筑规划与辅助放置的客户端 MOD。它可以把建筑保存成 ``.litematic`` 原理图，在游戏中加载为投影，显示材料清单，并按照投影逐步完成建造。

这篇内容按视频录制顺序整理，重点讲清楚四件事：**如何创建投影、如何加载投影、如何按投影放置，以及如何编辑和共享投影**。菜单名称和快捷键可能因游戏版本、MOD 版本或个人配置不同而变化，录制时请以当前配置页面显示的内容为准。

先理解三个词
------------------------

* **原理图（Schematic）**：保存下来的建筑文件，常见格式是 ``.litematic``。
* **投影（Placement）**：把原理图加载到当前世界后显示出来的实例。同一个原理图可以加载多次，每个投影都能单独移动或调整。
* **打印 / 放置**：按照投影中显示的方块，在世界里逐步放置真实方块。投影本身不会凭空生成方块，也不会替玩家获得材料。

视频开场口播
------------------------

还在对着教程一边看、一边数方块吗？Litematica 可以先把建筑保存成投影，再把它放进游戏世界里。我们可以先查看整体结构和材料清单，确定位置以后，再按照投影一层一层地建。今天从创建投影开始，依次讲到加载、放置、编辑，以及多人协作时如何同步。

创建投影
------------------------

创建投影前，先拿好 Litematica 当前设置的工具物品。默认通常是木棍；如果木棍没有反应，请先到配置中确认工具物品和按键是否被修改。

方法一：用两次点击框选
~~~~~~~~~~~~~~~~~~~~~~~~

#. 手持木棍，在建筑的一角 **左键** 设置第一个角点。
#. 在对角位置 **右键** 设置第二个角点。
#. 按 ``M`` 打开菜单，进入 **区域选择**，确认两个角点都落在目标建筑范围内。
#. 选择保存区域或保存为原理图，填写文件名后保存。

这种方法适合规则、边界清楚的建筑。录制时可以把两个角点和最终的包围盒都拍进画面，让观众看到“从选点到保存”的完整过程。

方法二：用坐标精确定位
~~~~~~~~~~~~~~~~~~~~~~~~

#. 手持木棍，按 ``M`` 打开菜单并进入 **区域选择**。
#. 选中第一个角点，将位置设置为玩家当前所在坐标，或者手工输入坐标。
#. 对第二个角点，可以直接填写坐标；也可以走到目标位置后，再使用“定位到玩家位置”。
#. 检查长、宽、高是否覆盖完整建筑，确认无误后保存为原理图。

坐标法更适合大型建筑或需要反复复刻的区域。建议录制时同时展示坐标和选择框，强调两个角点的坐标顺序不会改变最终的覆盖范围，但会影响你后续检查和沟通时的表述。

方法三：用视线和滚轮调整
~~~~~~~~~~~~~~~~~~~~~~~~

#. 先用木棍设置一个起始点和一个大致的目标点。
#. 按住 ``Alt``，朝目标方向观察，并滚动鼠标滚轮逐步调整选择范围。
#. 根据需要改变水平范围、垂直高度和朝向；调整到合适位置后，再回到 **区域选择** 菜单保存。

这种方法适合快速估算范围，但不如坐标法精确。不同版本可能把“调整选择区域”的快捷键分配给不同组合键，若滚轮没有反应，应在按键设置中搜索区域选择相关操作。

创建投影时的检查清单
~~~~~~~~~~~~~~~~~~~~~~~~

* 选择框是否包含了建筑最外层的方块和地基？
* 是否把不需要保存的地面、临时方块或周围地形一起选进去了？
* 建筑高度是否超出选择范围？
* 文件名是否包含建筑名称、方向或版本，方便之后查找？

加载投影
------------------------

#. 按 ``M`` 打开菜单，选择 **加载原理图**（或名称相近的加载入口）。
#. 在文件列表中选择要使用的 ``.litematic`` 文件并确认加载。
#. 打开投影配置，检查投影的原点、朝向和高度是否正确。
#. 需要多人一起建造时，可以先锁定投影，避免移动视角或操作时误拖位置。

加载完成后，投影只是一个“建造参考层”。常用的配置包括：

* **材料清单 HUD**：查看还缺哪些方块、已完成多少方块。
* **位置与朝向**：移动投影，或旋转、镜像后再确认与地形的关系。
* **显示范围**：隐藏暂时不施工的区域，减少画面遮挡。
* **锁定投影**：确认位置后锁定，避免误操作改变原点。

视频中建议先展示完整投影，再切换材料清单和位置调整，让观众先建立“文件 - 投影 - 世界”的对应关系。

投影打印：按照蓝图放置
------------------------

投影加载完成以后，再开始放置真实方块。这里的“打印”不是生成方块，而是让放置动作按照投影给出的目标方块进行。

基础放置
~~~~~~~~~~~~~~~~~~~~~~~~

#. 按 ``V`` 开启 **轻松放置（Easy Place）** 或当前配置中对应的投影放置模式。
#. 如果要在空中对照投影放置，确认相关的 **空中放置** 选项已经开启；该选项可能由 Litematica 或配套 MOD 提供。
#. 对准投影中的目标位置，右键可以逐个放置方块。
#. 按住右键沿着一行移动，可以连续处理同一行中符合投影的方块；放置前仍要确认手中拿的是正确方块。

自动放置
~~~~~~~~~~~~~~~~~~~~~~~~

在当前配置中，可以使用 ``Caps Lock`` 启用或触发自动放置。录制时请明确说明是“按一下切换”还是“按住生效”，不要把个人配置说成所有玩家的默认键位。

推荐的演示顺序是：先手动放置一个方块，再连续扫过一行，最后展示自动放置一小段。这样观众能看出每一步到底由哪个开关负责。

放置前的安全检查
~~~~~~~~~~~~~~~~~~~~~~~~

自动放置前，至少检查以下设置：

* 是否开启了需要的空中放置和轻松放置功能？
* 手长（交互距离）、放置间隔和放置频率是否合适？
* 手中方块是否与投影目标一致，背包里是否准备了足够材料？
* 当前服务器是否允许自动操作或快速连续放置？

放置频率过高可能触发服务器的 PPS（每秒数据包）或反作弊限制，严重时会被踢出服务器。建议先在单人世界或明确允许的测试服中验证，再逐步调高效率；多人服务器必须优先遵守服规。

投影编辑
------------------------

投影编辑可以分成“调整位置”和“修改内容”两类，录制时不要把两者混在一起：

位置与显示调整
~~~~~~~~~~~~~~~~~~~~~~~~

* 移动投影，让原点对齐地基、道路或其他固定参照物。
* 旋转或镜像投影，适配不同朝向的地形。
* 按图层或子区域显示，先隐藏暂时不施工的部分。
* 调整透明度、渲染范围和颜色，让投影不会遮住正在施工的画面。

原理图内容编辑
~~~~~~~~~~~~~~~~~~~~~~~~

需要修改蓝图本身时，进入当前版本提供的 **原理图编辑模式**，在副本上进行增删方块、替换材料或修改局部结构。编辑完成后另存为新文件，不要直接覆盖唯一的原始版本。

建议使用带版本号的文件名，例如 ``城堡_v02.litematic``、``城堡_屋顶修改_v03.litematic``，这样在回滚或多人协作时更容易确认大家使用的是同一份蓝图。

投影同步与多人协作
------------------------

上传与共享
~~~~~~~~~~~~~~~~~~~~~~~~

Litematica 负责保存和加载 ``.litematic`` 文件；“上传”通常需要借助网盘、代码仓库或其他文件分享工具完成。分享时同时提供文件名、版本号、Minecraft / Litematica 版本，以及一张预览图，接收者更容易判断文件是否匹配。

对齐蓝图
~~~~~~~~~~~~~~~~~~~~~~~~

协作前先约定一个固定基准点，例如地基左前角、道路交叉点或世界坐标。加载投影后，使用位置调整功能让基准点、朝向和高度与现场一致，再锁定投影。不要只凭屏幕上的大致位置判断，否则不同玩家很容易各自错开一格。

同步修改
~~~~~~~~~~~~~~~~~~~~~~~~

#. 修改前先复制一份原理图，保留上一版本作为回退。
#. 完成修改后另存为新版本，并在共享位置替换或上传新文件。
#. 在群里明确说明改了哪些区域、是否改变了原点或朝向。
#. 其他玩家重新加载新版本后，再继续施工；不要让多人同时修改同一个旧文件。

Litematica 不会自动把每个人本地的修改合并成一份云端蓝图。多人协作的关键是“统一文件、统一基准点、统一版本号”，而不是只把投影加载出来。

视频录制提纲
------------------------

可以按下面的顺序录制，整段视频会比较顺：

#. **开场**：用一句话说明 Litematica 解决的是“看着蓝图建建筑”这个问题。
#. **创建投影**：先演示木棍两点框选，再补充坐标定位和滚轮调整两种方法。
#. **加载投影**：展示原理图列表、投影位置、材料清单 HUD 和锁定功能。
#. **投影打印**：按“单个方块 - 一整行 - 自动放置”的顺序演示，并穿插安全提醒。
#. **投影编辑**：展示移动、旋转、隐藏区域，以及另存版本的习惯。
#. **投影同步**：用一个简短例子说明上传共享、基准点对齐和版本更新。
#. **结尾**：提醒观众先在单人世界测试，确认服务器规则后再使用自动放置。

视频结尾口播
------------------------

Litematica 的核心不是替你把建筑一键变出来，而是把复杂建筑拆成一份看得懂、对得齐、能逐步完成的施工图。先把投影创建准确，再确认位置和材料，最后按照服务器允许的方式放置。这样无论是自己复刻建筑，还是和朋友一起协作，都不容易在坐标、版本和材料上出错。

安装与版本提示
------------------------

* 安装与当前 Minecraft 版本匹配的 Litematica，以及它所需的 MaLiLib 和对应加载器。
* ``M``、``V``、``Caps Lock``、木棍左右键等都可能被个人配置修改；演示前先在按键设置中确认。
* 自动放置、空中放置和快速连续操作可能受到服务器规则或反作弊限制；不确定时只在单人世界或获得许可的服务器中使用。
