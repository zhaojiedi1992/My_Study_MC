============================================

Litematica 是一款用于 Minecraft 建筑规划与辅助放置的客户端 MOD。它可以把建筑保存成 ``.litematic`` 原理图，在游戏中加载为投影，显示材料清单，并按照投影逐步完成建造。

本文按实际操作顺序整理：先安装依赖并创建原理图，再加载、分层和放置；最后介绍创造模式快速放置、投影编辑、多人共享和公共目录配置。自动打印由 **Litematica Printer** 提供，多人共享由 **Syncmatica** 提供，这些功能不能都归到 Litematica 本体上。

安装与版本
----------

本期录制环境为 Minecraft Java 版 26.2。下面的版本号只用于说明本次实例，不是所有版本都能直接照抄；更换 Minecraft 版本时，应重新选择相互匹配的文件。

     - 安装关系
   * - Fabric Loader 0.19.3

     - 客户端基础环境
   * - Fabric API 0.154.1+26.2
     - 当前 Fabric 实例使用的基础 API

     - Litematica 的客户端依赖
   * - Litematica Printer 3.2.2
     - 打印模式、空中建造和自动连续放置

基础投影至少需要与 Minecraft 版本匹配的 Litematica 和 MaLiLib。只有需要自动打印时才额外安装 Litematica Printer；只有需要多人共享时才额外安装 Syncmatica。

先理解三个词
------------

* **原理图（Schematic）**：保存下来的建筑文件，常见格式是 ``.litematic``。
* **投影（Placement）**：把原理图加载到当前世界后显示出来的实例。同一个原理图可以加载多次，每个投影都能单独移动或调整。
* **放置 / 打印**：按照投影显示的目标，在世界里放置真实方块。投影不会凭空生成方块，也不会替玩家获得材料。

创建投影
--------

创建前先拿好 Litematica 当前设置的工具物品，默认通常是木棍。木棍没有反应时，先到配置中确认工具物品和按键是否被修改。

选择选区工具
~~~~~~~~~~~~~~

#. 手持工具，按住 ``Ctrl`` 并滚动鼠标滚轮，在工具模式之间切换。
#. 直到工具 HUD 或当前模式显示为“选区工具”（部分版本会写成“区域选择”）后，再设置角点。
#. 如果没有切换到选区工具模式，木棍的左右键可能会执行其他工具操作。

``Ctrl + 鼠标滚轮`` 是本期演示使用的快捷键；没有反应时，在按键设置中搜索“操作模式变更修饰键”或“工具模式”。

两点框选
~~~~~~~~

#. 在建筑的一角 **左键** 设置第一个角点。
#. 在对角位置 **右键** 设置第二个角点。
#. 按 ``M`` 打开菜单，进入 **区域编辑器** 或 **选区浏览器**，检查选择框是否覆盖目标建筑。
#. 选择保存区域或保存为原理图，填写文件名后保存。

大型建筑也可以在区域编辑器中直接输入两个角点的坐标。坐标法比凭视线估算更容易复核，保存前应确认长、宽、高包含了地基、最高层和需要保留的方块。

如果只是快速估算范围，也可以先设置大致角点，再按住 ``Alt`` 并滚动鼠标滚轮调整选择区域。滚轮调整适合快速取景，但精度不如坐标法；最终保存前仍应回到区域编辑器复核边界。

创建时检查：

* 是否包含建筑最外层方块和地基？
* 是否误选了不需要保存的地面、临时方块或周围地形？
* 文件名是否包含建筑名称、方向或版本，方便之后查找？

加载与定位投影
--------------

#. 按 ``M`` 打开菜单，选择“加载原理图”（或名称相近的加载入口）。
#. 在文件列表中选择 ``.litematic`` 文件并确认加载。
#. 打开投影配置，检查维度、原点、朝向和高度。
#. 移动、旋转或镜像投影，使它与地基、道路或其他固定参照物对齐。
#. 位置确认后锁定投影，避免操作时误拖原点。

加载完成后，投影只是建造参考层。常用显示项包括材料清单 HUD、投影位置与朝向、图层或子区域显示、透明度和渲染范围。大型建筑建议先隐藏暂时不施工的部分，画面会更清楚。

投影放置与打印
--------------

投影加载完成以后，再开始放置真实方块。“打印”不是生成方块，而是让放置动作按照投影给出的目标方块进行。

生存模式的轻松放置
~~~~~~~~~~~~~~~~~~

#. 在 Litematica 配置中开启 **轻松放置模式（Easy Place Mode）**。本期实例没有把 ``easyPlaceToggle`` 固定绑定为 ``V``，因此录制或使用前要先确认自己的按键。
#. 对准投影中的目标位置，使用当前配置的放置键逐个放置；本期实例的 ``easyPlaceUseKey`` 是鼠标右键。
#. 需要连续处理时，开启 **轻松放置 - 按住启用**，按住放置键并移动视线。
#. 手中仍要准备正确的方块和足够的材料；轻松放置不会替你补充物品。

自动打印（Litematica Printer）
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Litematica Printer 的配置中需要打开 **打印 - 模式**；如果要在空中打印，还要打开 **打印 - 空中建造**。本期实例的打印模式切换键是 ``Caps Lock``，打印热键本身没有预先绑定，按住打印前应在按键设置中分配按键。

打印速度由 **打印间隔** 控制，放置距离由 **打印范围** 控制。遇到幽灵方块、方块朝向错误或服务器限制时，应先提高间隔、降低范围，不要一开始就追求最高速度。

放置前检查：

* 是否开启了需要的轻松放置、打印模式和空中建造？
* 手中方块是否与投影目标一致，背包里是否有足够材料？
* 当前服务器是否允许自动操作或快速连续放置？

放置频率过高可能触发服务器的 PPS 或反作弊限制。建议先在单人世界或明确允许的测试服验证，多人服务器优先遵守服规。

分层放置
--------

大型投影不要一次显示全部结构。可以按楼层、子区域或施工顺序逐步显示：

#. 先在投影配置中隐藏暂时不施工的图层或子区域。
#. 从地基或最低层开始，确认当前层的材料和边界。
#. 完成一层后再显示下一层，必要时锁定已经对齐的投影。
#. 发生错位时，先回到固定基准点检查原点和朝向，不要直接拖动整张投影碰运气。

分层显示既适合生存建造，也适合录制教程；它能减少线框遮挡，并让材料清单更容易对应当前施工范围。

创造模式直接放置
------------------

创造模式可以快速补齐投影中的结构，但它和生存模式的轻松放置、自动打印不是同一套使用场景：创造模式不需要准备材料，也不应拿来推断生存服的放置限制。

使用前仍建议先确认投影位置、朝向和选择范围；大型结构可以配合分层显示，逐层检查后再放置。需要在服务器使用时，仍要遵守服务器规则，不要因为处于创造模式就跳过权限和安全检查。

投影编辑
--------

投影编辑分为“调整投影实例”和“修改原理图内容”两类。修改蓝图前先复制一份原文件，编辑完成后另存为带版本号的新文件。

调整投影实例
~~~~~~~~~~~~~~

* 移动投影，让原点对齐地基、道路或其他固定参照物。
* 旋转或镜像投影，适配不同朝向的地形。
* 按图层或子区域显示，隐藏暂时不施工的部分。
* 调整透明度、渲染范围和颜色，避免投影遮住施工画面。

修改原理图内容
~~~~~~~~~~~~~~~~

在当前版本提供的 **原理图编辑模式** 中，常见操作包括：

#. **删除特定方块**：在当前选择位置或范围内删除目标方块。
#. **替换特定方块**：指定旧方块和新方块，在选定位置或范围内替换。
#. **替换所有特定方块**：在整张原理图中查找旧方块并批量替换。

这些操作的作用范围可能受当前选择区域、编辑工具或菜单选项影响。执行批量替换前，先确认旧方块和新方块没有选反，并检查预览结果。建议使用 ``城堡_v02.litematic``、``城堡_屋顶修改_v03.litematic`` 这类文件名，便于回滚和协作。

投影共享与多人协作
------------------

Litematica 负责本地保存和加载 ``.litematic`` 文件；本期通过 **Syncmatica** 把投影放到服务器上共享。多人服务器通常要在客户端和服务端都安装匹配版本的 Syncmatica，单人世界则由客户端实例中的集成服务端处理同步。

推荐流程：

#. 先在原理图管理器中确认文件可以正常加载；不兼容时按提示转换后再分享。
#. 确认维度、原点坐标、朝向、Minecraft 版本和 Litematica 版本。
#. 在共享入口中选择 **分享**；本期版本提示需要按住 ``Shift`` 才能完成分享。
#. 其他玩家打开 **共享投影图**，下载或加载对应投影，再按需要打开材料清单。
#. 修改前复制原理图，完成后另存为新版本，并明确说明改动区域、原点和朝向。

协作前先约定固定基准点，例如地基左前角、道路交叉点或世界坐标。Syncmatica 不是无冲突的多人合并工具；多人协作的关键仍然是统一文件、统一基准点和统一版本号，不要让多人同时修改同一个旧文件。

配置投影公共目录
----------------

需要在多个实例中使用同一批投影时，可以把它们指向同一个公共目录。这样能避免每个实例各存一份文件，也方便团队统一更新。

#. 在文件管理器中创建一个专门的投影目录，例如 ``D:\Minecraft\Litematica\schematics``。
#. 关闭正在运行的 Minecraft 实例，避免配置写入时互相覆盖。
#. 在 Litematica 的文件或目录配置中，把原理图目录改为这个公共目录。
#. 逐个实例检查目录是否可读，并加载一份测试原理图确认路径生效。
#. 公共目录要定期备份；多人共享时仍需用版本号区分不同修改。

不同系统和启动器的配置入口、路径格式可能不同，视频中的 Windows 示例不能直接套用到 Linux 或 macOS。路径改动后如果列表为空，先检查目录权限、文件扩展名和实例是否实际使用了预期的配置文件。

快捷键与故障排查
----------------

``M``、``V``、``Caps Lock``、木棍左右键和 ``Ctrl`` 修饰键都可能被个人配置或其他 MOD 改写。遇到“按键没反应”时，按下面顺序排查：

#. 在按键设置中搜索功能名称，确认是否已绑定以及是否发生冲突。
#. 在 Litematica/Printer 配置中确认功能开关，而不是只看键位。
#. 检查 Litematica、MaLiLib、Printer、Syncmatica 与 Minecraft 版本是否匹配。
#. 先在单人世界复现，再判断是否是服务器权限、反作弊或数据同步问题。

自动放置、空中建造和快速连续操作可能受到服务器规则或反作弊限制。不确定时只在单人世界或获得许可的服务器中使用。

常见问题（FAQ）
----------------

为什么按 ``M`` 没有反应？
~~~~~~~~~~~~~~~~~~~~~~~~~

先在按键设置中搜索 Litematica 菜单，确认 ``M`` 仍然绑定且没有和其他 MOD 冲突。若按键绑定正常，再确认当前实例确实加载了 Litematica 和 MaLiLib；只安装 Litematica 而缺少 MaLiLib 时，菜单通常无法正常工作。

为什么木棍没有选区反应？
~~~~~~~~~~~~~~~~~~~~~~~~

木棍只是当前配置的工具物品，不一定是所有实例的默认工具。先在 Litematica 配置中确认工具物品，再用 ``Ctrl + 鼠标滚轮`` 切换到选区工具模式。工具模式不对时，左右键可能会执行其他操作。

投影加载了，但画面里看不见怎么办？
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

先检查投影是否加载在正确的维度、原点和高度，再确认主渲染、透明度、渲染范围和图层显示没有被关闭。也要检查自己是否站在投影范围附近；如果只显示部分结构，可能是当前启用了子区域或图层过滤。

为什么投影和建筑总是错一格？
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

不要只凭屏幕上的大致位置移动投影。选一个固定基准点，例如地基左前角或世界坐标，检查原点、朝向和高度，再锁定投影。协作时所有玩家必须使用同一个基准点，旋转或镜像后也要重新复核。

为什么右键放不出投影里的方块？
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

轻松放置只改变放置动作的目标，不会替你提供材料。先确认手中方块与投影目标一致、背包中有足够材料，并检查 ``easyPlaceUseKey`` 是否仍然是鼠标右键。如果是服务器，放置权限、交互距离和反作弊也可能阻止操作。

轻松放置和 Litematica Printer 有什么区别？
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

轻松放置是 Litematica 本体提供的辅助放置功能，通常需要玩家持续瞄准并使用放置键；Printer 是额外 MOD，提供打印模式、空中建造和更连续的自动放置。两者的开关和按键分别配置，不要把 Printer 的选项当成 Litematica 默认功能。

Printer 开启了，为什么还是不打印？
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

确认 Printer 的 **打印 - 模式** 已开启，并检查打印热键是否真的绑定。若要空中打印，还要开启 **打印 - 空中建造**。随后从一个方块或很短的一段开始测试，检查打印间隔、范围、手中方块和服务器限制；出现幽灵方块时先提高间隔、降低范围。

为什么分层后有些方块消失了？
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

分层显示通常只是隐藏图层或子区域，不会删除原理图内容。打开投影配置，检查当前显示层、子区域过滤和渲染范围；确认无误后再显示下一层。编辑模式中的删除操作才会真正改变蓝图，编辑前应先保留副本。

创造模式直接放置和生存打印一样吗？
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

不一样。创造模式不需要准备材料，适合快速补齐和检查结构；生存模式仍受背包、交互距离、服务器权限和反作弊限制。创造模式能放置不代表生存服务器允许使用 Printer 或空中建造。

为什么 Syncmatica 看不到共享投影？
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

先确认客户端和服务端都安装了匹配版本的 Syncmatica，并检查当前服务器是否允许共享功能。分享前还要确认投影所在维度、原点、朝向和版本；如果文件本身无法在原理图管理器中加载，先解决文件兼容性再分享。

多人能不能同时编辑同一个投影？
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

不建议把它当成多人合并工具。修改前复制原理图，完成后另存为新版本，明确改动区域和基准点，再让队友重新加载新版本。多人同时修改同一个旧文件，容易造成覆盖、错位和版本不一致。

为什么加载原理图时提示版本不兼容？
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

检查 Minecraft、Fabric Loader、Litematica、MaLiLib 以及 Printer/Syncmatica 的版本组合。不同版本可能需要转换原理图格式；转换前保留原始文件，不要直接覆盖唯一副本。下载模组时应以当前 Minecraft 版本对应的文件为准。

为什么配置了公共目录，但列表仍然是空的？
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

确认目录路径指向实际存放 ``.litematic`` 文件的位置，而不是上一级目录；再检查文件扩展名、目录权限和当前实例实际使用的配置文件。修改目录后完全重启 Minecraft，逐个实例加载测试文件，排除启动器使用了另一套实例目录的情况。

自动放置会不会被服务器封禁？
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

有可能。快速连续放置、空中建造和高频打印可能违反服务器规则或触发反作弊。第一次使用时应在单人世界或明确允许的测试服中验证，并把打印间隔、范围和频率调低；不确定时不要在公开服务器启用。
