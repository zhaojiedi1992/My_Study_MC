LuckPerms 分组批量操作指令
==================================================

.. code-block:: text

    将上面的表格， 和这个需求内容， 直接让豆包给生成下luckperm的权限语句吧。 
    需求： 
    1. 删除这些用户组。 default保留就好，改成modify语句的。 
    2. 创建这些用户组， 显示名字为第二列+第三列。 权重为权重列。 
    3. 3. 按照这个顺序进行tracks设置名字，xiuxian_tongdao，  方便后面我可以让用户花金币升级，比如这个/luckperms user Notch promote xiuxian_tongdao 每个需求分割出来。
    4. 将用户升级到下一级的金币，放到group的meta信息里面，meta 名为为  shengji_jinbi
    5. /lp creategroup <name> [weight] [displayname]  这个命令是这个语法。 
    6. 给具体的分组补充家的权限  huskhomes.max_homes.<amount>   dominion.limitation.<分组名字> 权限。
    7. 分组的名字是拼音数字的，不要带中文， 显示名字为中文的。
    8. 导出的指令不要带前缀/

批量导入方法1
==================================================

将所有命令保存为一个 user_info.txt 文件，每行一条 LuckPerms 命令，不带 / 前缀。
上传到服务器 /plugins/LuckPerms/ 目录。
在游戏或控制台执行：`/lp import user_info.txt` 
这个不太行了， 具体参考这里： https://luckperms.net/wiki/General-Commands#lp-import-filecode---upload---replace
