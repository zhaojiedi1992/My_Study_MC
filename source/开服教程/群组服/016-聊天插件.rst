Carbon的简介
==================================================

`文档介绍 <https://github.com/Hexaoxide/Carbon/wiki>`_ 
`下载地址 <https://modrinth.com/plugin/carbon>`_ 


.. code-block:: bash 

    # 下载插件
    wget https://cdn.modrinth.com/data/QzooIsZI/versions/2ptKcv94/carbonchat-paper-3.0.0-beta.32.jar
    # 改名放到plugin目录里面来。 
    # 重启
    systemctl restart mc_login 



权限设置
==================================================

.. code-block:: bash 

    # 创建一个普通的carbot权限组。
    /lp creategroup g-carbot 0  g-carbot
    # 让默认组继承carbot组
    /lp group default parent add g-carbot

    # 给carbot普通组安排权限
    # 基础聊天权限
    /lp group g-carbot permission set  carbon.channel.global true 
    /lp group g-carbot permission set  carbon.channel.global.speak true 
    /lp group g-carbot permission set carbonchat.chat.enabled true
    /lp group g-carbot permission set carbonchat.chat.color true       # 允许使用&颜色代码
    /lp group g-carbot permission set carbonchat.chat.formatting true   # 允许使用格式化代码(加粗/斜体等)
    /lp group g-carbot permission set carbonchat.emoji.use true         # 允许使用表情符号
    /lp group g-carbot permission set carbonchat.emoji.list true        # 允许查看表情符号列表
    /lp group g-carbot permission set carbonchat.channel.local.send true # 允许发送到本地频道
    /lp group g-carbot permission set carbonchat.channel.local.receive true # 允许接收本地频道消息
    # 社交功能
    /lp group g-carbot permission set carbonchat.socialspy.exempt true  # 免被社交监控
    /lp group g-carbot permission set carbonchat.ignore.use true        # 允许使用/ignore命令
    /lp group g-carbot permission set carbonchat.reply.use true         # 允许使用/r命令

    # 聊天标签和装饰
    /lp group g-carbot permission set carbonchat.tag.prefix.use true    # 允许使用前缀
    /lp group g-carbot permission set carbonchat.tag.suffix.use true    # 允许使用后缀
    /lp group g-carbot permission set carbonchat.tag.color.use true     # 允许使用颜色标签

    # 表情符号白名单(可选，限制使用特定表情)
    #/lp group g-carbot permission set carbonchat.emoji.use.* false      # 禁用所有表情
    #/lp group g-carbot permission set carbonchat.emoji.use.smile true   # 启用特定表情
    #/lp group g-carbot permission set carbonchat.emoji.use.heart true

    # 防止滥用
    /lp group g-carbot permission set carbonchat.spam.block true        # 启用防刷屏
    /lp group g-carbot permission set carbonchat.caps.block true        # 启用大写限制
    /lp group g-carbot permission set carbonchat.url.block true         # 启用URL过滤
