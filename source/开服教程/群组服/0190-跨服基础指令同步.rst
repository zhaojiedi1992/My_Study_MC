跨服基础指令同步
==================================================
我们群组服， 用户A在分区1，用户B在分区2， 需要直接tp过去， 需要插件支持，不然只能分区内的才能传输， 另外home也是同理的。 



`huskhomes <https://william278.net/docs/huskhomes/setup>`_

==================================================
.. code-block:: sql 

    --  创建一个db, 方便luckperm权限插件使用的。 
    CREATE DATABASE d_huskhomes CHARACTER SET utf8 COLLATE utf8_general_ci;

解决命令冲突问题
==================================================
home命令，tp命令，其实在 EssentialsX都有的， 不过这个是仅仅分区内使用的， 我们这个huskhome是可以跨分区的。 如果不做配置还是使用的老的命令，导致不符合预期。

.. code-block:: bash 

    # EssentialsX config.yml file 找个disabled-commands 位置，设置如下内容。 
    disabled-commands:
    - home
    - homes
    - sethome
    - homelist
    - delhome
    - warp
    - setwarp
    - createwarp 
    - warplist
    - delwarp
    - tp
    - tphere
    - tpa
    - tpahere
    - tpaccept
    - tpdeny
    - tpno
    - rtp
    - tpignore
    - tpoffline
    - tpall
    - tpaall
    - spawn
    - setspawn
    - back

如果还有其他的问题，可以参考 `冲突问题 <https://william278.net/docs/huskhomes/command-conflicts>`_
