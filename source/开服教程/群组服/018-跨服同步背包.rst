跨服插件
==================================================
我们是群组服的， 一个proxy+多个分区的，玩家的背包，末影箱这些期望用户在从生存区转到登录区，是可以同步的。 
dl1分区，大家根据情况决定是否要同步。


husksync
==================================================
这个是开源的， 不过jar包是收费的， 我们可以自己编译的。 

- 无缝同步： 当玩家更换服务器时，利用优化的 Redis 缓存超快速同步玩家数据，实现无缝体验。
- 完整的玩家同步： 同步库存、末影箱、健康、饥饿、效果、进步、统计数据、锁定的地图等——不会遗漏任何数据！
- 备份、恢复和轮换： 出错了？将玩家数据恢复到之前的状态。在游戏中轮换和管理数据快照！
- 导入现有数据： 导入你的 MySQLPlayerDataBridge 数据，或从你现有的世界数据导入！无需重置服务器！
- 与 Plan 完美配合： 通过 Plan 网络面板上的 HuskSync 分析与您的社区保持联系。
- 可扩展 API 且开源： 需要更多？使用开发者 API 扩展插件。或者，通过我们的代码赏金系统提交拉取请求！

- docs: https://william278.net/docs/husksync/
- github: https://github.com/WiIIiam278/HuskSync

构建husksync.jar包
==================================================

.. code-block:: bash 

    # 下载下来他的源码
    git clone git@github.com:WiIIiam278/HuskSync.git

    # 切换分支， 这个按需了， 要看版本那个支持了。 
    git checkout 3.8.5 
    # 构建
    ./gradlew clean build

    # 如果提示错误， snapshot的，可以在这个页面搜索，https://mvnrepository.com/artifact/net.kyori/adventure-platform-fabric/6.5.1  搜索一下版本，看看更新一下配置文件让他获取正确的版本。 
    # build.gradle 的仓库可以新增一些。 
    # maven { url 'https://maven.fabricmc.net/' }
    # maven { url 'https://api.modrinth.com/maven' }

    # 构建完毕后， target目录就有构建结果了。 


创建数据库
==================================================
.. code-block:: sql 

    CREATE DATABASE d_HuskSync CHARACTER SET utf8 COLLATE utf8_general_ci;
