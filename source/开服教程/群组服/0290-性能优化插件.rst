性能优化插件
==================================================
服务器经常会因为红石、动物过多导致的卡顿， 需要就这个问题进行必要的限制。 可以考虑看看julysafe这个插件。 不过是开源收费的， 可以自己编译安装的。

插件对比
==================================================
市面上常见的性能优化插件有以下几种：

- **JulySafe**：功能全面，支持自动重启、实体清理、红石限制等，适合需要细致控制的服务器。开源但需付费授权，可自行编译。
- **ClearLag**：老牌实体清理插件，配置简单，适合新手，但功能相对单一。
- **PaperMC**：服务端优化分支，内置大量性能优化选项，适合追求极致性能的服务器。
- **Spark**：性能分析工具，主要用于查找卡顿原因，非直接优化插件。

JulySafe 相比 ClearLag 功能更丰富，支持更多细致的限制和防护措施，适合对服务器性能有更高要求的用户。

安装
==================================================
julysafe 是需要开源收费的， 你可以自己编译下的。 他的依赖项也是作者自己的插件， 也是需要编译的。

1. 克隆 JulySafe 和 VoidFramework 仓库到本地：
   ```
   git clone https://github.com/julyss2019/JulySafe.git
   git clone https://github.com/julyss2019/VoidFramework-Bukkit.git
   ```
2. 使用 Maven 或 Gradle 编译两个项目，生成 jar 文件。
3. 将编译好的 jar 文件放入服务器的 `plugins` 文件夹。
4. 重启服务器，检查插件是否正常加载。

问题QA
==================================================
**Q: JulySafe 支持哪些服务端？**  
A: 主要支持 Spigot、Paper 及其分支，建议使用 Paper 以获得最佳兼容性。

**Q: 插件收费吗？**  
A: 插件本身开源，但需要购买授权才能合法使用。自己编译也是可以使用的。

**Q: 插件和 ClearLag 有什么区别？**  
A: JulySafe 功能更全面，支持更多细致的限制和防护措施，适合对性能有更高要求的服务器。

**Q: 编译遇到问题怎么办？**  
A: 建议先阅读官方文档，或在 GitHub issue 区提问，作者和社区会提供帮助。

**Q: 插件会影响正常游戏体验吗？**  
A: 合理配置下不会影响正常体验，建议根据实际需求调整各
