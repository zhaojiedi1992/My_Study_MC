插件管理安装
==================================================

本节介绍如何在群组服环境下安装和使用插件管理工具（如 Plugin Portal、PlugManX、ServerUtils），实现插件的热重载、在线安装、批量管理等功能，提升运维效率。

插件管理工具简介
==================================================
插件管理工具可以在不重启服务器的情况下，快速加载、卸载、更新插件，适合测试环境和前期频繁调整插件的场景。

功能说明
==================================================
Plugin Portal 是一款支持游戏内插件市场搜索、在线安装和更新的管理插件，支持 SpigotMC、Modrinth、Hangar 三大市场，适用于多分区和 Proxy 环境。

Plugin Portal简介
==================================================
- 支持游戏内直接安装、更新插件
- 三大市场资源搜索与下载

- 自动过滤非活动/弃用插件
- 支持 1.8+ 所有主流服务端
- 插件自我更新

.. warning:: 生产环境请勿随意更新插件，部分插件大版本不兼容，更新前务必备份。

安装步骤
==================================================
1. 下载插件管理工具（如 Plugin Portal jar 包）
2. 放置到所有分区和 Proxy 的 plugins 目录
3. 重启所有服务端

.. code-block:: bash

    # 查看插件列表
    /pp list
    # 下载插件
    /pp download <name>
    # 更新插件
    /pp update <name>

.. warning:: 更新插件前请备份，避免因兼容性问题导致服务异常。

配置与使用建议
==================================================
- 推荐仅在测试/开发环境安装，生产环境慎用热重载和在线更新功能
- 插件管理工具本身无需复杂配置，安装即用
- 可结合 PlugManX 实现插件的启用/禁用/重载

常见问题 QA
==================================================
:Q1: 插件安装后无效或报错？  
:A1: 检查服务端版本、依赖是否齐全，查看日志分析原因。

:Q2: 插件下载失败？  
:A2: 检查网络连接、市场源是否可用，或手动下载 jar 包安装。

:Q3: 插件更新后服务异常？  
:A3: 可能因插件大版本不兼容，建议回滚或联系插件作者。

:Q4: 如何验证插件是否正常工作？  
:A4: 游戏内输入 `/plugins` 查看插件列表，绿色为正常，红色为异常，具体原因见服务端日志。
