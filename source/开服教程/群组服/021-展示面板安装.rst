==================================================
TAB插件安装
==================================================
这里主要是tab可以展示服务器的玩家信息 + 计分板可以展示右侧的公告信息。


简介
==================================================

- `帮助文档 <https://github.com/NEZNAMY/TAB/wiki/Installation>`_ 

`bridge  <https://github.com/NEZNAMY/TAB-Bridge/releases>`_ 
`tab <https://github.com/NEZNAMY/TAB/releases>`_ 

根据帮助文档里面介绍，我们群组服，需要再proxy安装tab, 然后后端的分区安装TAB-Bridge 就可以了。 


创建数据库
==================================================
.. code-block:: sql 

    --  创建一个db, 方便luckperm权限插件使用的。 
    CREATE DATABASE d_tab CHARACTER SET utf8 COLLATE utf8_general_ci;
