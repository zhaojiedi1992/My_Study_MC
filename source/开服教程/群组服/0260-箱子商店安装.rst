==================================================
箱子商店安装
==================================================
箱子商店插件允许玩家在箱子上点击创建商店，支持卖出和收购两种类型，广泛用于生存区、地皮区等玩家自由交易场景。

插件简介
==================================================
- 支持一键创建买/卖商店，操作简单
- 完美兼容 NBT 数据、附魔、药水、蛋等特殊物品
- 国际化支持，自动切换客户端语言
- 无限商店、黑名单、权限分级等高级功能
- 支持双箱、UUID、聊天/GUI物品预览
- 强力兼容世界/区域保护插件
- 支持多种经济插件（Vault、GemsEconomy、TheNewEconomy等）
- 税收、持续费用、权限管理、缓存优化
- 支持 H2（本地）或 MySQL（远程）数据库
- 高级事件总线与开发者API
- 性能极佳，支持千级商店无延迟（需 ProtocolLib）

安装步骤
==================================================
1. 从 SpigotMC 下载 QuickShop-Hikari.jar
2. 放到目标分区的 plugins 目录（如地皮区 dp1、生存区 sc1）
3. 重启服务端

==================================================

权限配置
==================================================
参考官方 plugin.yml，推荐如下分组授权：

.. code-block:: bash

  # 创建箱子商店普通权限组
  /lp creategroup g-quickshop 0 g-quickshop

  # 将 default 组继承箱子商店普通权限组
  /lp group default parent add g-quickshop

  # 给 g-quickshop 组分配玩家基础权限
  /lp group g-quickshop permission set quickshop.player true


测试方法
==================================================
进入游戏，放置一个箱子，拿钻石左键点击箱子，若弹出创建商店提示则插件安装成功。 

如果没有反应，可以通过luckperm的verbose来debug下。

常见问题 QA
==================================================
:Q1: 无法创建商店或命令无效？  
:A1: 检查插件是否安装、数据库配置是否正确，查看服务端日志。

:Q2: 经济功能无法使用？  
:A2: 检查 Vault 或其他经济插件是否安装，数据库连接是否正常。

:Q3: 玩家无法管理商店？  
:A3: 检查 LuckPerms 权限配置，确认已授权 quickshop.player/quickshop.moderator/quickshop.admin。

:Q4: 跨服消息不同步？  
:A4: 检查 bungee-cross-server-msg 参数是否开启，所有分区配置是否一致。

优化建议
==================================================
- 推荐所有分区统一安装 QuickShop-Hikari，保证体验一致
- 使用 MySQL 数据库后端，提升性能和数据安全
- 定期备份数据库，防止玩家商店数据丢失
- 合理分配权限，避免玩家滥用商店功能
- 配合 Vault、LuckPerms、ProtocolLib 等插件实现完整体验
