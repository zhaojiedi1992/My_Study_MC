简介
==================================================

- 使用方便，只需单击并输入价格即可创建商店。
- NBT 数据、附魔、工具伤害、药水和生物蛋支持。
- 根据客户端语言动态切换显示语言，国际化友好。
- 无限商店支持。- 黑名单支持和绕过权限。
- 在双箱中买卖物品的商店。
- UUID 支持（当然）
- 聊天和 GUI 中的酷炫物品预览。
- 聊天控制面板用于更改商店设置。只需点击即可修改所有内容。
- 支持世界/地区保护插件，并可下载大量兼容模块。
- 基于ProtocolLib的虚拟 DisplayItem（性能更佳）支持。
- 支持多种货币，您可以在 GemsEconomy、TheNewEconomy 或任何支持 Reserve 的经济体商店中使用不同的货币。当然，我们也支持 Vault（默认）！
- 税收和持续费用支持！
- 如果玩家没有权限，则隐藏帮助命令。
- 标示标题颜色并在信息标志上清晰描述不同商店的状态。
- 支持迷你消息，随心所欲创建精美消息。
- H2（本地）或 MySQL（远程）支持。
- 先进的交易机制，当执行失败时回滚任何库存/经济操作以防止玩家重复。
- InventoryWrapper API 为开发人员提供自定义库存功能。
- 高级事件总线允许用户阻止保护检查事件传输到特定插件。
- 快速缓存层，处理超过 1000+ 个商店，无任何延迟！（需要安装 ProtocolLib）
- 每个商店的权限管理。
- 店主与其他玩家之间的购物福利！

下载安装
==================================================
直接从spigotmc下载jar包即可。放到plugins目录， 重启一下分区。


创建数据库
==================================================

.. code-block:: bash 

  CREATE DATABASE d_quickshop CHARACTER SET utf8 COLLATE utf8_general_ci;

测试
==================================================
进入游戏， 找个地方，放置一个箱子， 然后拿一个钻石左键这个箱子， 看是否会提示创建商店的信息，如果无，那就是插件安装不符合预期的。
