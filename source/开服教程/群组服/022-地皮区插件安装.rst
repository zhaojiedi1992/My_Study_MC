==================================================
地皮插件安装
==================================================
地皮插件是为了更好服务新手的，可以让新手快速的有一个小地方，进行存放物资使用的。


安装
==================================================
这个是收费的， 需要下载下来官方的源码，然后执行./gradlew clean build 构建一下，然后包在bukkit/libs目录。 
复制jar包到dp1分区。 

这个插件是依赖worldedit 或者fast sync worldedit 的，建议你安装fast sync world edit 就好。

.. note:: 注意了，这个是主需要在地皮区安装的，其他的去不用安装的。


创建db
==================================================
.. code-block:: bash 

    CREATE DATABASE d_plot_db CHARACTER SET utf8 COLLATE utf8_general_ci;

重新覆盖world
==================================================
我们通过上面的指令会生成一个world.yml文件， 在启动的时候会生成一个world的， 不过我们现在world世界已经存在了， 需要删除掉，让他检测和生成。 

.. code-block:: bash 

    systemctl stop mc_dp1 
    mv /home/mc/instances/dp1/world /home/mc/instances/dp1/world.bak
    systemctl start mc_dp1 

地皮中心区域的规划
==================================================
地皮的中心方格，不建议给普通用户使用，我们这里占用中间的4个格子，方便后期给中心区域做一些建筑。 

.. code-block:: bash 
    
    # 进入地皮中心区域， 设置一个区域吧。 
    plot setowner 
    # 连续给中心的4个都设置下owenr
    ...
    # 合并4个为1个。
    plot merge
