==================================================
NPC插件安装
==================================================
NPC插件，可以在系统里面提供一些交互能力，提升游玩特性。 

这里还是选择这个经典款的。 

- `Citizens2 <https://github.com/CitizensDev/Citizens2>`_ 
- `wiki <https://wiki.citizensnpcs.co/Citizens_Wiki>`_ 
- `Citizens2 ci <https://ci.citizensnpcs.co/job/Citizens2/>`_ 


- `Denizen <https://ci.citizensnpcs.co/job/Denizen/>`_ 

安装
==================================================
从上面ci的链接获取最新的开发版本即可,需要Citizens2 + Denizen
放到plugins目录，然后重启下。 


配置登录1区
==================================================

.. code-block:: bash 

# 进入游戏，后，/dom tp dl1 然后执行如下指令创建一个main机器人
1. 创建一个npc
/npc create &3熊猫乐园
2. 设置自动转头，看用户。
/npc lookclose
3. 设置右键执行那个命令, 用户身份执行cmd命令。 相当于用户直接输入/cmd  这个需要配合菜单使用的， 菜单你绑定的命令是啥这里就是啥。 
/npc command add -p cmd
4. 配置保存
/citizens save



配置生存区域npc
==================================================
设计一个5*5*5的空间大小的位置，然后掏空直接，让中间形成一个3*3*3的空间。 
然后再里面放置2npc, 分别对应rtp机器人， 主菜单机器人。

.. code-block:: bash 

    # 进入游戏后进入生存一区0,0,0位置，然后布局一个3*3*3空间，然后圈地，/dom auto_creae sc1
    1. 创建一个npc
    /npc create &3点击主菜单
    #2. 设置自动转头，看用户。
    /npc lookclose
    #3. 设置右键执行那个命令, 用户身份执行cmd命令。 相当于用户直接输入/cmd  这个需要配合菜单使用的， 菜单你绑定的命令是啥这里就是啥。 
    /npc command add -p cmd
    #4. 设置下主菜单的皮肤为我自己的皮肤,要是正版用户id
    /npc skin mc__panda


    # 生存2区设置
    #1. 创建一个npc
    /npc create &3点我随机tp
    #2. 设置自动转头，看用户。
    /npc lookclose
    #3. 设置右键执行那个命令, 
    /npc command add -p rtp
    #4. 镜像皮肤
    /npc mirrorskin

    /citizens save


    # 登录分区设置。
    同理一样的。


.. note:: 这里地皮一区，你也可以参考这个配置下， 不过我是通过全息文字配置的。 具体自己参考下面的文档进行配置。
