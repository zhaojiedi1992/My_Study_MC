==================================================
Plugin Portal插件管理安装
==================================================
Plugin Portal是一个可以在游戏内快速进行插件管理的一个插件， 可以非常方便进行插件管理，我们需要进行安装。


`Plugin Portal 下载 <https://www.spigotmc.org/resources/plugin-portal.108700/>`_ 


安装
==================================================

下载好文件， 放置到plugin目录，重启即可。 需要各个分区+proxy都安装的。
安装好后进行重启。 


.. code-block:: bash 

    # 就可以查看所有的插件列表
    /pp list  

    # 下载可以已使用/pp download 下面我会将使用的


.. warning::  主要谨慎使用这个插件， 避免插件更新导致的服务异常。 如果启用这个，关闭自动更新。 




如何验证我的插件是否正常工作
==================================================
进入游戏输入/plugins 即可， 看看具体的列表， 绿色的就是正常的，红色的是异常的。需要看日志分析的。
