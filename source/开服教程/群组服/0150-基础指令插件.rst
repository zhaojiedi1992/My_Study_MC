基础指令插件安装
==================================================

EssentialsX 是 Spigot 服务器的必备插件，为任何大小和规模的服务器提供核心功能。  
本节介绍 EssentialsX 的安装、权限配置、常见问题和优化建议，适用于所有分区。

插件简介
==================================================
EssentialsX 提供了如下核心功能：

- 玩家设置家与传送
- 服务器路径点和新手工具包
- 玩家私聊、邮件、经济系统
- 传送请求与接受
- 审核工具：踢出、禁言、监禁、临时禁止
- 内置经济功能，支持 Vault
- 服务器公告、MOTD、规则等

安装步骤
==================================================
1. 下载 EssentialsXCore 和 EssentialsXSpawn 两个 jar 包
2. 放到所有分区的 plugins 目录
3. 重启所有服务端，确认插件正常加载

.. code-block:: bash

    wget https://github.com/EssentialsX/Essentials/releases/latest/download/EssentialsX.jar
    wget https://github.com/EssentialsX/Essentials/releases/latest/download/EssentialsXSpawn.jar
    cp EssentialsX*.jar /home/mc/instances/dl1/plugins/
    cp EssentialsX*.jar /home/mc/instances/dp1/plugins/
    cp EssentialsX*.jar /home/mc/instances/sc1/plugins/
    cp EssentialsX*.jar /home/mc/instances/sc2/plugins/
    # 重启所有服务端

配置说明
==================================================
- EssentialsX 默认配置即可满足大多数需求
- 可根据实际需求修改 config.yml（如家数量、经济单位、欢迎消息等）
- 推荐所有分区都安装，保证指令一致性

常见问题 QA
==================================================
:Q1: 安装后部分指令无效？  
:A1: 检查 LuckPerms 权限配置，确认已授权 essentials.* 相关权限。

:Q2: 家数量限制不生效？  
:A2: 修改 EssentialsX config.yml 的 home 数量设置，重载插件。

:Q3: 经济功能无法使用？  
:A3: 检查 Vault 是否已安装，EssentialsX 经济依赖 Vault。

:Q4: 指令冲突或报错？  
:A4: 检查是否有其他插件覆盖了 EssentialsX 的指令，建议只保留一个同类插件。
