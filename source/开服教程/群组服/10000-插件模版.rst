性能优化插件（JulySafe/ClearLag等）
==================================================
本节介绍 Minecraft 服务器常用的性能优化插件，帮助提升服务器稳定性和流畅度，减少因红石、实体等造成的卡顿。

这里给推荐选择项：  
- **JulySafe**：适合对性能和细节有较高要求的服务器，功能丰富，支持多种限制和防护措施。
- **ClearLag**：适合新手或只需简单实体清理的场景。
- **PaperMC**：建议所有服务器优先选择 Paper 服务端，内置大量优化选项。
- **Spark**：用于性能分析和定位卡顿原因，配合其他插件使用。

JulySafe 插件介绍
==================================================
JulySafe 是一款功能全面的性能优化插件，支持自动重启、实体清理、红石限制、命令频率限制等多种功能。适合需要细致性能管控的服务器。插件开源，但需购买授权后合法使用，也可自行编译。

主要特性包括：
- 自动重启
- 方块防爆
- 实体防爆
- 实体清理
- 区块密集实体清理
- 实体生成限制
- 掉落物清理
- 火蔓延限制
- 聊天黑名单
- 聊天频率限制
- 命令黑名单
- 命令频率限制
- 农作物防踩踏
- 非法玩家限制
- 掉落物拾取记录
- 掉落物丢弃记录
- 高频红石限制

下载安装
==================================================
JulySafe 是需要开源收费的，你可以自己编译下的。它的依赖项也是作者自己的插件，也需要编译。

1. 克隆 JulySafe 和 VoidFramework 仓库到本地：
   ```
   git clone https://github.com/julyss2019/JulySafe.git
   git clone https://github.com/julyss2019/VoidFramework-Bukkit.git
   # 这个项目是需要java8的，需要你下载一个java8 配置下java8的环境变量。
   ```
2. 使用 Maven 或 Gradle 编译两个项目，生成 jar 文件。
3. 将编译好的 jar 文件放入服务器的 `plugins` 文件夹，这里主要jar的大小，别copy错误的了。
4. 重启服务器，检查插件是否正常加载。

luckperm权限配置
==================================================
JulySafe 支持权限系统，可通过 LuckPerms 等插件分配管理权限。常用权限节点包括：
- `julysafe.admin`：管理全部功能
- `julysafe.bypass`：绕过部分限制
- `julysafe.command.*`：使用所有 JulySafe 命令

.. code-block:: bash 

    /lp group owner permission by 


具体权限节点和说明请参考官方文档。

游戏内设置
==================================================
JulySafe 支持部分命令操作，可在游戏内进行部分功能的开关和参数调整。常用命令如：
- `/julysafe reload`：重载配置
- `/julysafe clear`：手动清理实体
- `/julysafe info`：查看插件状态

更多命令和用法详见官方文档。

问题QA
==================================================
:Q1:  JulySafe 支持哪些服务端？  
:A1:  主要支持 Spigot、Paper 及其分支，建议使用 Paper 以获得最佳兼容性。

:Q2:  插件收费吗？  
:A2:  插件本身开源，但需要购买授权才能合法使用。自己编译也是可以使用的。

:Q3:  插件和 ClearLag 有什么区别？  
:A3:  JulySafe 功能更全面，支持更多细致的限制和防护措施，适合对性能有更高要求的服务器。

:Q4:  编译遇到问题怎么办？  
:A4:  建议找其他的同学帮忙协助，或者通过ai工具给你指导编译。

:Q5:  插件会影响正常游戏体验吗？  
:A5:  合理配置下不会影响正常体验，建议根据实际需求调整各项参数。

:Q6:  JulySafe 支持哪些常见优化功能？  
:A6:  包括自动重启、实体清理、红石限制、爆炸防护、聊天/命令限制等，详见上方功能列表。
