SkinsRestorer
==================================================
可以让盗版用户设置皮肤， 比如用户A看到一个正版用户的皮肤比较好看，可以通过命令直接让自己在游戏内的皮肤修改下。

.. code-block:: sql 

    --  创建一个db, 方便luckperm权限插件使用的。 
    CREATE DATABASE d_skinsrestorer CHARACTER SET utf8 COLLATE utf8_general_ci;


`skinrestorer官方地址 <https://skinsrestorer.net/>`_ 
安装没啥问题， 直接放到plugin目录即可，修改项目比较少， 参考下面的即可。


.. code-block:: bash 

    root@mc:/home/mc/instances/login/plugins/SkinsRestorer# diff config.yml config.yml.default
    59,60c59,60
    <     enabled: true
    <     host: 127.0.0.1
    ---
    >     enabled: false
    >     host: localhost
    62,65c62,65
    <     database: d_skinsrestorer
    <     username: mc
    <     password: mc_panda_142857
    <     maxPoolSize: 100
    ---
    >     database: db
    >     username: root
    >     password: pass
    >     maxPoolSize: 10

.. note:: 注意了， 这个插件是需要proxy + server都要放置的， 仅仅server是不太行的。

给普通用户添加玩家权限

.. code-block:: bash 

    /lp group default permission set skinsrestorer.player true 


箱子排序
==================================================

ChestSort 可以在您使用后自动对每个箱子、木桶等进行排序。每个玩家都可以使用简单的命令/sort（或 /chestsort）启用或禁用此功能。玩家还可以使用命令/invsort对自己的物品栏进行排序，或者使用/invsort on|off自动排序。如果您不想自动排序，也可以在玩家物品栏、箱子等中使用热键（鼠标中键单击、双击、按住 Shift 单击和按住 Shift 并右键单击）对其进行排序。

- spigotmc: https://www.spigotmc.org/resources/chestsort-api.59773/
- github: https://github.com/mfnalex/ChestSort
