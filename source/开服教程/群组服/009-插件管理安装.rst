Plugin Portal简介
==================================================
是一款游戏内插件下载和更新工具，使用 SpigotMC、Modrinth 和 Hangar 市场。您可以轻松通过 Minecraft 聊天栏查看资源数据、安装和更新插件。对我看来，他的核心卖点是游戏内可以直接download，避免用户在网上瞎找。

一些特性如下

- 直接安装：您可以使用单个命令直接从游戏中安装来自 Spigot、Modrinth 和 Hangar 的插件！
- 插件列表：我们从三个市场扫描了超过 10 万个插件，可供下载！您可以直接在这个庞大的列表中输入内容并进行搜索。
- 插件预览：检查插件是否正确。使用/pp view命令，您可以查看游戏中的资源图标、描述、状态和评分，从而确保插件正确。
- 跨版本兼容性：我们兼容 1.8+ 的每个版本，并支持所有主要服务器 jar，包括 Folia！
- 无非活动插件：我们已自动为您过滤所有非活动/已弃用/已废弃的插件，以免您意外下载不再可用的插件。（别担心 - 如果您必须下载，仍然可以这样做）
- 自我更新：插件门户当然可以自行更新！无需离开舒适的聊天栏。

.. warning:: 对于生产环境，请误随意更新插件的版本， 主要是有些插件不一定向下兼容，尤其大版本更新。

安装
==================================================

下载好文件， 放置到plugin目录，重启即可。 需要各个分区+proxy都安装的。
安装好后进行重启。 


.. code-block:: bash 

    # 就可以查看所有的插件列表
    /pp list  
    # 下载插件
    /pp download <name>
    # 更新插件
    /pp update <name>

.. warning::  请谨慎使用这个插件更新功能， 避免插件更新导致的服务异常。

如何验证我的插件是否正常工作
==================================================
进入游戏输入/plugins 即可， 看看具体的列表， 绿色的就是正常的，红色的是异常的。红色的需要看日志分析的。主要的原因包含如下几个，你可以按需进行排查。

1. 版本检查： 核对你下载的版本和你的mc server端是否匹配。
2. 依赖检查： 核对你的这个插件，需要哪些前置依赖，前置依赖需要进行安装。
3. db没有创建： 大部分插件都会使用mysql db数据库作为存储的， 如果他的database没有创建也是不行的，需要你创建了database,他才能创建表，正常工作。
4. 配置项错误： 如果你的配置文件里面的配置项错误，可能也会导致插件不工作，具体以日志的消息为准
