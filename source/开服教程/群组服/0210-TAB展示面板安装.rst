推荐选择项
==================================================
- **TAB + TAB-Bridge**：群组服首选，支持Proxy与所有分区同步，功能最全，兼容性最佳。
- 其他插件适合单服或小型服务器，群组服建议统一用TAB方案。

简介
==================================================
TAB插件支持Tab列表美化、分组排序、前缀后缀、计分板、跨服同步等功能。  
TAB-Bridge用于后端分区与Proxy的数据同步，保证所有分区展示一致。

- `帮助文档 <https://github.com/NEZNAMY/TAB/wiki/Installation>`_ 
- `TAB-Bridge下载 <https://github.com/NEZNAMY/TAB-Bridge/releases>`_ 
- `TAB下载 <https://github.com/NEZNAMY/TAB/releases>`_ 
- `LuckPerms推荐 <https://luckperms.net/wiki/Prefixes,-Suffixes-&-Meta>`_

安装方案
==================================================
群组服环境下，需在Proxy安装TAB，在所有后端分区安装TAB-Bridge。

创建数据库
==================================================
.. code-block:: sql 

    --  创建一个db, 方便luckperm权限插件使用的。 
    CREATE DATABASE d_tab CHARACTER SET utf8 COLLATE utf8_general_ci;

proxy侧的安装
==================================================
.. code-block:: bash 

    # 将tab.jar 放到proxy的plugin目录， 
    cp TAB.jar /home/mc/instances/proxy/plugins/
    # 配置 config.yml，设置数据库、分组、计分板等参数
    # 参考下方配置差异和完整示例

后端分区安装
==================================================
.. code-block:: bash

    # 将TAB-Bridge.jar 放到所有分区的 plugins 目录
    cp TAB-Bridge.jar /home/mc/instances/dl1/plugins/
    cp TAB-Bridge.jar /home/mc/instances/dp1/plugins/
    cp TAB-Bridge.jar /home/mc/instances/sc1/plugins/
    cp TAB-Bridge.jar /home/mc/instances/sc2/plugins/
    # 重启所有服务端

常见问题 QA
==================================================
:Q1: TAB列表或计分板不显示？  
:A1: 检查TAB和TAB-Bridge是否都已安装，配置文件是否正确，重启服务端。

:Q2: 分组、前缀、变量不显示？  
:A2: 检查LuckPerms权限组配置，变量需配合PlaceholderAPI使用。

:Q3: 跨服同步异常？  
:A3: 检查Proxy和所有分区TAB/TAB-Bridge版本是否一致，数据库配置是否统一。

:Q4: 计分板内容不刷新？  
:A4: 检查PlaceholderAPI变量扩展是否安装，TAB配置刷新间隔是否合理。
