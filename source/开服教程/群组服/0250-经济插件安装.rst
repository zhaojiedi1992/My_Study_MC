==================================================
经济插件安装
==================================================
虽然essentinal里面也提供了经济能力， 不过这个没法跨分区的，太伤了。 需要另外的经济插件来支持的， 简单说让每个分区都使用一个db就好。

- spigotmc: https://www.spigotmc.org/resources/xconomy.75669/
- github: https://github.com/YiC200333/XConomy

.. note:: 这个插件有个++版本的， 不建议安装， 这个版本就非常好， 就经济非常纯粹。


安装
==================================================
你下载的是一个zip包，需要你解压好， 获取大paper的jar放到plugins里面去。


创建数据库
==================================================
.. code-block:: sql 

    CREATE DATABASE d_playerpoint CHARACTER SET utf8 COLLATE utf8_general_ci;

配置修改
==================================================
基本就是需要修改下数据库部分，其他的改动比较少。

.. code-block:: bash 

    # 主要是修改下语言， bungee的这个可以改，可以不该。
    root@mc:/home/mc/instances/dl1/plugins/XConomy# diff config.yml config.yml.default
    19c19
    <   language: Chinese
    ---
    >   language: English
    102c102
    <   enable: true
    ---
    >   enable: false

    # database文件，需要修改为数据的， 其他的redis ,h2这些都不要动就行。

QA环节
==================================================

:Q1: java.lang.NullPointerException: Cannot invoke "java.sql.Connection.prepareStatement(String)" because "connection" is null
:A1: dtabase.yml的 usepool: true 请设置好， 然后重启就好了。 

:Q2: 怎么核对我的/money命令是使用的essentinal的还是XConomy的？
:A2: 这个问题，可以从几个方面看。
    1. 看服务器日志， 有类似这样的消息。[Essentials] Rcon issued server command: /bc 分区dp1准备重启5s...
    2. 通过luckperm的debug能力,比如。 /lp verbose command <me|player> <command>
    3. 其他的插件来支持命令来自的path
