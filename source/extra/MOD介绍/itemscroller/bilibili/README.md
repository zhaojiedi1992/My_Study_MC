## 简介

还在箱子和背包之间一个个点击物品吗？本期介绍 Item Scroller：一款专注移动物品、批量丢弃和极速合成的 Minecraft 效率 MOD。

📚 完整图文文档、快捷键说明与 PPT 风格实机演示：
https://docs.mc.linuxpanda.tech/zh-cn/latest/MOD%E4%BB%8B%E7%BB%8D/itemscroller/itemscroller.html

本期重点：

- 移动物品：单个、固定数量、一个堆叠、同类全部和拖动批量移动
- 丢弃物品：按 Q 逐个丢、按住连续丢、Shift + Q 批量清理
- 合成物品：保存常用配方、批量合成和循环合成
