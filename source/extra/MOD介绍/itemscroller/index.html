什么是 Item Scroller？

让 1 分钟的操作
变成 1 秒

📦
移动物品
按需要移动 1 个、固定数量、1 组、同类全部或容器里的所有物品。
🗑️
丢弃物品
想精准丢弃就逐个丢；挖矿回来要清理多格垃圾时，可连续批量丢弃。
⚡
合成物品
保存常用配方，需要大量成品时批量或循环合成，减少反复摆放材料和点击。

移动物品 · 01

📦 按数量移动

从 1 个、固定数量到所有物品，按当前需求选择操作

我现在想移这样操作
1 个物品精准微调数量 悬停后 滚动 1 次
多个物品（固定数量）例如拆出半组，或准确移动 8 个 右键 拆半，或悬停后 上/下滚 N 次
1 组（整堆）例如一堆 64 个圆石 Shift + 滚动
同一种物品的全部把容器里该种物品全部移走 Alt + 滚动
容器里的所有物品一次清空当前容器 Alt + Shift + 滚动
💡 方向感知：向上滚 = 移进背包，向下滚 = 放进容器。位置感知模式可自动判断方向！

合成物品 · 01

📋 保存常用配方

再也不用记怎么合成了，全都存起来！

1️⃣
打开合成台
在工作台前方摆好配方材料
2️⃣
按住 A 键
显示配方面板，共 8 页 × 18 个配方槽
3️⃣
中键点击保存
配方自动保存，退出游戏也不会丢失
📌
面板内快捷操作
左键选中 · 右键选中并合成一次 · 数字键 1-9 直选 · 方向键切换页面
💾
持久化存储
配方保存在 .minecraft/itemscroller/，支持全局模式（所有存档共用）

合成物品 · 02

⚡ 批量合成物品

材料充足？一个按键，自动量产到材料耗尽

Ctrl + C
批量合成一轮
将背包里能合成的材料全部转移，合成一次，结果放回背包
Ctrl + Alt + C
🔥 持续按住→无限循环
持续执行循环合成，直到材料耗尽或松开快捷键
🎯 实战场景： 需要 512 个木板？存好木板配方 → 把木头放进背包 → 按住 Ctrl+Alt+C → 全自动量产，不用点一下鼠标！

快速上手

🔧 安装指南

📥 下载安装
  • 确认安装了 Fabric 加载器
  • 在 CurseForge / Modrinth 搜索 Item Scroller
  • 下载 .jar 文件放入 mods/ 文件夹
  • 启动游戏，自动生效！🎉
