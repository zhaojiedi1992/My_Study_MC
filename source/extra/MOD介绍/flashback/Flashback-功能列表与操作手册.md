# Flashback：功能列表与操作手册

> Flashback 是 Moulberry 开发的 Minecraft Java 版客户端回放与镜头制作 MOD。它记录的是可以在游戏内重新播放、编辑的回放数据，不是直接录制屏幕视频。
>
> 本文已按官方最新源码 `0.41.1`（Minecraft 26.2）核对，源码提交为 `a612fea`，核对日期为 2026-07-24。旧版 Flashback 的菜单、键位和可用功能可能不同，请以对应版本实际界面为准。

## 一句话理解工作流程

```text
正常游玩时录制回放
        ↓
保存为 Flashback 回放压缩包
        ↓
在主菜单打开回放
        ↓
用时间轴、自由相机和关键帧编排镜头
        ↓
调整画面、实体、声音和导出范围
        ↓
导出视频、图片或图片序列
```

Flashback 适合制作建筑展示、服务器活动记录、剧情短片、运镜镜头和教程素材。它不是监控全服的服务器录像工具：在多人服务器中，客户端主要记录自己实际接收到的区块、实体和数据。

## 功能总览

| 功能组 | 主要能力 |
| --- | --- |
| 回放录制 | 开始、暂停、恢复、完成或取消录制；自动开始和自动结束；异常退出后的未完成录制恢复 |
| 录制标记 | 手动标记精彩时刻；保存颜色、说明、坐标和维度；切换维度时自动加标记 |
| 回放管理 | 搜索、排序、重命名、删除、从外部文件打开，以及把两段回放首尾合并 |
| 时间轴编辑 | 播放、暂停、快慢速、跳转、缩放、入点/出点、多个编辑场景、轨道管理和撤销/重做 |
| 镜头制作 | 自由相机、相机路径、相机环绕、实体追踪、视野变化、镜头滚转和相机抖动 |
| 时间控制 | 速度关键帧、延时关键帧、冻结关键帧，以及按真实时间或游戏 Tick 插值 |
| 画面控制 | 隐藏界面元素、方块、玩家、实体、粒子和天空；覆盖迷雾、时间、天气、夜视和天空颜色 |
| 实体处理 | 旁观、传送、注视、导出时隐藏、改名、换皮肤、隐藏披风/装备/模型部件、强制发光 |
| 音频 | 导出游戏声音；选择相机或实体作为听音位置；添加外部音频轨；可选录制 Simple Voice Chat |
| 导出 | 视频、截图、PNG 序列；分辨率、帧率、码率、编码器、音频、透明天空、SSAA 和导出队列 |

## 详细功能列表

### 1. 录制与标记

- 暂停菜单提供开始、暂停、恢复、完成和取消按钮，按钮可以放在菜单左侧、右侧、下方或隐藏。
- 可以设置进入世界/服务器后自动开始录制，离开时自动完成录制。
- “完成录制”会保留内容并进入保存流程；“取消录制”会删除本次临时录制，不能恢复。
- 可以开启快速保存，跳过命名界面并按日期时间自动生成文件。
- 可在回放中记录本地玩家的高频位置和角度，适合之后导出自己的第一人称视角。
- 可选记录第一人称快捷栏信息。
- 切换维度时可以自动加入时间轴标记。
- 支持 4 组可配置的标记快捷键，每组都能设置颜色、说明和是否保存当前位置。
- 安装 Simple Voice Chat 后，可选把语音聊天写入回放。
- 安装 Bobby 后，可选把当前可见的 Bobby 缓存区块直接写入回放。
- 游戏在录制中异常退出时，Flashback 会尝试恢复临时录制；由于录制按最长约 5 分钟分块，末尾最多可能丢失约 5 分钟。

### 2. 回放文件管理

- 主菜单增加“打开回放”入口。
- 回放列表支持搜索，并可按创建日期、回放名称、世界名称、时长或文件大小排序。
- 可以修改回放显示名称、删除回放，或从任意位置选择 `.zip` 回放文件打开。
- 可以把两个兼容回放按“第一段在前、第二段在后”的顺序首尾合并；第二段的标记会自动顺延。
- 打开回放前会检查游戏版本、协议版本、数据版本和注册表信息，并对不兼容或可能不兼容的文件发出警告。

### 3. 时间轴与编辑场景

- 拖动播放头定位任意 Tick，控制播放、暂停、减速、快进和前后跳转。
- 录制时添加的标记会显示在时间轴上；点击带位置的标记，还会跳到对应时刻并在同一维度中靠近该位置。
- 可设置导出入点和出点，只导出时间轴中的目标片段。
- 时间轴支持滚轮缩放、拖动缩放条、移动显示区域和框选关键帧。
- 关键帧可以移动、复制、粘贴、删除、批量选择、对齐和缩放时间间距。
- 支持撤销和重做关键帧编辑。
- 轨道可以启用/禁用、重命名、改颜色、调整顺序、清空或删除。
- 同一份回放可以创建多个“场景”，为不同成片保留不同的关键帧轨道和导出范围。
- 编辑状态默认约每 30 秒自动保存，并保留一份 `.old` 备份。

### 4. 可创建的关键帧

`0.41.1` 的普通编辑界面可以创建以下 10 类关键帧：

| 关键帧 | 用途 | 常见场景 |
| --- | --- | --- |
| 相机 | 保存相机位置、朝向和滚转 | 直线、曲线和定点运镜 |
| 相机环绕 | 围绕指定中心、距离和角度运动 | 建筑、人物或机器环拍 |
| 追踪实体 | 追踪实体的头部、身体或脚部，并设置位置/视角偏移 | 跟拍玩家、怪物或载具 |
| 相机抖动 | 调整水平/垂直方向的频率和幅度 | 爆炸、奔跑、冲击镜头 |
| 视野（FOV） | 改变镜头视野 | 推拉感、远景压缩、强调主体 |
| 速度 | 改变回放 Tick 速度 | 慢动作、加速和速度渐变 |
| 延时 | 把一段较长的游戏时间映射到指定成片时长 | 建造延时、昼夜延时 |
| 一天中的时间 | 覆盖游戏时间 | 日落、夜景和时间过渡 |
| 冻结 | 冻结或恢复回放，可设置平滑减速延迟 | 定格介绍、时间停止效果 |
| 音频轨 | 加载外部音频文件并在时间轴播放 | 音效、音乐或对白参考 |

源码中还注册了“方块覆盖”类型，但 `0.41.1` 将它标记为不能通过普通时间轴创建，因此本文不把它当作面向普通用户的可用功能。

### 5. 关键帧插值

关键帧之间可以使用：

- 平滑（Smooth）
- 线性（Linear）
- 缓入（Ease In）
- 缓出（Ease Out）
- 缓入/缓出（Ease In/Out）
- 保持（Hold）
- Hermite

平滑或 Hermite 适合连续运镜；线性适合匀速；缓入/缓出适合自然起步和停车；保持适合参数在某一刻突然切换。插值既可以按真实成片时间计算，也可以改为按回放 Tick 计算。

### 6. 自由相机与移动控制

- 回放中可以脱离原玩家，以自由相机在已记录场景里飞行。
- 在主画面操作相机时，鼠标滚轮可以调整飞行速度。
- 移动方向可选择“水平”或“跟随相机方向”。
- 可调整飞行惯性，并锁定 X、Y、Z、偏航或俯仰，方便制作水平平移、垂直升降和固定方向镜头。
- 可以显示三分法辅助线、中心辅助线和三维相机路径。
- 画面尺寸支持保持比例、更改比例、填充和底层模式；内置 16:9、9:16、2.40:1、1:1、4:3 和 3:2 比例。

### 7. 视觉控制

编辑器的“视觉”窗口可以控制：

- 界面：聊天、Boss 血条、标题、记分板、操作栏和可用时的快捷栏。
- 世界：方块、实体、玩家、粒子、天空、名称标签和信标光柱。
- 天空：关闭原天空后自定义纯色天空，并可在导出时生成透明天空。
- 迷雾：覆盖开始距离、结束距离和颜色。
- 镜头：覆盖 FOV、相机抖动和镜头滚转。
- 环境：覆盖一天中的时间、天气和夜视。
- 构图：三分法辅助线、中心辅助线和相机路径。
- 服务器资源包：回放包含服务器资源包时，可以选择禁用它。

其中 FOV、时间和相机抖动既能设为整段固定值，也能从视觉窗口直接添加对应关键帧。

### 8. 玩家、实体和粒子

“玩家列表”可以搜索玩家或 NPC，并提供传送、旁观、导出时隐藏、全部隐藏和全部显示。

在回放世界里右键玩家或实体，可以：

- 让相机看向目标、旁观目标或复制 UUID；
- 把目标设为音频来源；
- 安装 Simple Voice Chat 时单独静音某人的语音；
- 仅在导出时隐藏目标；
- 强制发光或强制取消发光；
- 对玩家隐藏披风、名称标签、队伍前后缀和名字下方文本；
- 修改显示名称；
- 从 UUID 应用其他玩家的皮肤，或从本地 PNG 文件载入皮肤；
- 隐藏生物装备和玩家模型部件。

“渲染过滤”可以按实体种类或粒子种类整体开关。粒子过滤只阻止新的粒子生成，已经出现的粒子不会立刻消失。

### 9. 音频

- 视频导出可以同时录制游戏声音，并选择单声道或立体声。
- 默认从相机位置听音；也可以右键实体，将听音位置绑定到该实体。
- 音频轨可以加载 `mp3`、`ogg`、`wav`、`aiff`、`au`、`flac` 或 `opus` 文件。
- 可用音频编码包括 AAC、MP3、Opus 和 Vorbis，实际选项取决于所选容器和运行环境。
- Simple Voice Chat 的内容只有在录制前开启“录制语音聊天”时才会进入回放；事后无法从没有录到的回放中补回。

### 10. 视频与截图导出

导出时可以设置：

- 分辨率、帧率、开始/结束 Tick；
- 透视、正交、立方体贴图和等距柱状投影；
- 重置随机数、SSAA 超采样和隐藏全部界面；
- 视频容器、编码器、码率、音频和透明天空；
- 立即导出，或加入导出队列后批量执行。

源码列出的容器包括 MP4、MKV、AVI、MOV、PNG 序列、WebP、WebM 和 GIF；编码包括 H.264、H.265、AV1、VP9、Apple ProRes、QuickTime、WebP 和 GIF。Flashback 会在运行时检测真正可用的组合，因此不是每台电脑都会显示全部编码器。

截图也支持自定义分辨率、投影方式、SSAA、隐藏界面和透明天空。

## 安装与版本要求

本文的最新源码组合如下：

| 组件 | `0.41.1` 源码要求 | 说明 |
| --- | --- | --- |
| Minecraft Java 版 | 26.2 | `0.41.1` 不应直接安装到旧版游戏 |
| Java | 21 或更高 | 以启动器实际使用的 Java 为准 |
| Fabric Loader | 0.15.10 或更高 | 官方 `26.2` 构建使用 0.19.3 |
| Fabric API | 0.107.0 或更高 | 必需依赖；官方 `26.2` 构建使用 0.153.0+26.2 |
| Flashback | 0.41.1 | 客户端必装，服务器端不需要安装 |

安装步骤：

1. 为目标 Minecraft 版本创建 Fabric 实例。
2. 安装与游戏版本匹配的 Fabric API。
3. 从官方 Modrinth 页面下载与游戏版本完全对应的 Flashback JAR。
4. 把 JAR 放进该实例的 `mods` 目录。
5. 启动游戏，在主菜单确认出现 Flashback 的“打开回放”图标。

旧 Minecraft 版本应在 Modrinth 的版本列表中选择对应文件，不要只看 Flashback 版本号相同就混装。

## 第一次使用前的推荐设置

进入“Flashback 选项”，先检查以下项目：

1. **自动完成录制**：建议开启，正常退出世界时自动收尾。
2. **自动开始录制**：只在希望每次都录制时开启，否则会产生大量回放文件。
3. **快速保存**：新手建议先关闭，完成后手动命名，便于辨认回放。
4. **标记维度切换**：建议开启。
5. **第一人称更新率**：只在要导出自己的第一人称时提高；计划导出 60 fps，可考虑录制前设为 60 次/秒。数值越高，录制开销和文件体积通常也越大。
6. **录制快捷栏**：需要重现第一人称 HUD 时再开启。
7. **录制语音聊天**：需要录制 Simple Voice Chat 时必须提前开启，并先征得参与者同意。
8. **标记快捷键**：给至少一组标记绑定一个不冲突的按键。

## 操作手册

### 第一步：开始和结束录制

1. 进入单人世界或多人服务器。
2. 按 `Esc` 打开暂停菜单。
3. 点击 Flashback 的“开始录制”。
4. 正常游玩；需要跳过无用过程时，可以暂停录制，再恢复录制。
5. 录制完成后点击“完成录制”。
6. 填写回放名称，确认文件名和保存位置，然后保存。

不要把“完成录制”和“取消录制”混淆：取消会删除本次临时录制。

### 第二步：在录制中添加标记

有三种常用方式：

- 使用预先绑定的标记快捷键；
- 输入 `/flashback mark` 添加默认红色标记；
- 输入带参数的命令，例如 `/flashback mark #55aaff true 城堡开门`。

参数依次是颜色、是否保存当前位置、说明。颜色可以使用 `red` 等颜色名，也可以写十六进制 RGB。保存位置后，回放中点击该标记不仅跳转时间，还能在同一维度里靠近标记位置。

### 第三步：打开和整理回放

1. 返回 Minecraft 主菜单。
2. 点击 Flashback 的“打开回放”图标。
3. 使用搜索框查找回放，必要时切换排序字段和升降序。
4. 选中回放后点击“打开回放”。
5. 如果回放不在默认目录，选择“从文件加载回放”。
6. 需要重命名或合并时，先选中回放再进入“编辑”。

遇到版本或注册表警告时，不要直接忽略。尽量使用录制当时相同的 Minecraft 版本、模组集合、资源包和数据包环境。

### 第四步：熟悉回放编辑器

- 底部是时间轴和关键帧轨道。
- 主画面是自由相机预览。
- 顶部“文件”菜单负责视频、截图、最近回放和退出回放。
- 顶部还可以打开偏好设置、玩家列表、移动、渲染过滤和快捷键窗口。
- “视觉”窗口负责界面、世界、天空、天气、FOV 和构图辅助。
- 按 `F1` 可以隐藏或恢复回放编辑界面。

先用播放、暂停、左右方向键和时间轴拖动找到目标片段，再开始添加关键帧。

### 第五步：制作第一条相机路径

1. 在场景画面里把自由相机移动到镜头起点。
2. 把时间轴播放头放在起始 Tick。
3. 点击时间轴左下角“添加元素”，新建“相机”轨道。
4. 点击该轨道右侧的 `+`，保存第一个相机关键帧。
5. 把播放头移动到镜头结束位置。
6. 将自由相机飞到终点，再点击同一轨道的 `+`。
7. 播放预览，观察路径和朝向变化。
8. 右键关键帧修改插值；镜头过冲时先尝试线性或缓入/缓出，镜头太硬时再尝试平滑。
9. 打开“视觉 → 相机路径”检查三维路径。

复杂镜头建议先用少量关键帧确定大形状，再增加中间点修正，不要一开始堆很多点。

### 第六步：制作环绕和实体跟拍

环绕固定建筑时：

1. 新建“相机环绕”轨道。
2. 为关键帧填写环绕中心、距离、偏航和俯仰。
3. 在后续时间点改变偏航角，保持中心和距离一致，即可形成环拍。

跟拍玩家或生物时：

1. 右键目标并复制 UUID，或从实体信息中取得 UUID。
2. 新建“追踪实体”轨道并填写 UUID。
3. 选择头部、身体或脚部作为跟踪基准。
4. 用位置偏移决定相机相对位置，用视角偏移、偏航、俯仰和滚转微调构图。

如果只要完全跟随某个玩家的原视角，可以直接旁观该玩家；这种情况下通常不需要再建普通相机关键帧。

### 第七步：设置速度、定格和延时

- **慢动作/加速**：新建“速度”轨道，使用两个或更多关键帧设定倍率变化。
- **定格**：添加“冻结”关键帧；需要自然停住时增加冻结延迟，使回放先减速再停止。
- **延时**：延时至少需要两个关键帧。左侧设置基准时间，例如 `0s`；右侧设置成片中希望经过的时长，例如 `10s`。

速度、延时和“按真实时间插值”会相互影响。第一次制作时建议只启用一种时间控制，确认结果后再叠加。

### 第八步：调整画面和实体

1. 在“视觉”中关闭不需要的聊天、记分板、名称标签或粒子。
2. 根据成片需要覆盖时间、天气、FOV、迷雾和天空。
3. 需要透明背景时，先关闭“渲染天空”，再在导出窗口开启“透明天空”。
4. 单独处理某个玩家时，在画面中右键该玩家。
5. 批量隐藏某类生物或粒子时，使用“渲染过滤”。
6. 只想让某个实体不出现在最终成片时，使用“导出时隐藏”，不要误以为它等同于全局渲染过滤。

### 第九步：设置声音

1. 先确认原回放确实录到了需要的游戏声音或语音聊天。
2. 默认以相机为音源位置；要模拟某个玩家听到的声音，右键该玩家并设为音频来源。
3. 需要额外音乐或音效时，新建“音频轨”，选择本地音频文件。
4. 导出窗口中开启“录制音频”，选择单声道/立体声和编码格式。
5. 先导出几秒测试片段，确认声音、画面和关键帧同步，再导出长视频。

### 第十步：导出视频

1. 按 `I` 设置导出入点，按 `O` 设置出点。
2. 从顶部“文件 → 导出视频”打开导出窗口。
3. 设置分辨率和帧率。普通横屏视频可从 `1920 × 1080 / 60 fps` 开始测试。
4. 选择投影方式。普通视频使用“透视”；立方体贴图建议 4:3；等距柱状投影建议 2:1。
5. 按需求开启重置随机数、SSAA、无界面和透明天空。
6. 选择容器、编码、编码器和码率。通用发布优先考虑 MP4 + H.264。
7. 需要声音时开启录制音频。
8. 选择保存位置，开始导出；多段镜头可以加入导出队列。
9. 导出完成后打开文件检查画面、声音、时长和透明通道是否符合预期。

高分辨率、高帧率、SSAA、透明背景、复杂光影和虚拟渲染帧都会显著增加导出时间。先用短片段验证，再开始长时间导出。

## 命令速查

### 录制命令

```text
/flashback start
/flashback pause
/flashback unpause
/flashback finish
/flashback end
/flashback config
/flashback mark
/flashback mark <颜色> <是否保存位置> <说明>
```

`finish` 和 `end` 作用相同。暂停、恢复和完成命令只应在对应录制状态下使用。

### 回放内实体命令

```text
/hide <实体选择器>
/show <实体选择器>
```

这两个命令控制实体是否在导出时显示。例如：

```text
/hide @e[type=minecraft:zombie]
/show @e[type=minecraft:zombie]
```

如果其他模组已经占用了 `/hide` 或 `/show`，Flashback 会改用 `/hide_flashback` 或 `/show_flashback`。

## 文件位置与备份

以下路径都相对于当前 Minecraft 实例目录：

| 内容 | 默认位置 |
| --- | --- |
| 回放文件 | `flashback/replays/*.zip` |
| 编辑状态 | `flashback/editor_states/<回放 UUID>.json` |
| 编辑状态备份 | `flashback/editor_states/<回放 UUID>.json.old` |
| 临时录制与回放服务 | `flashback/temp/` |
| Flashback 配置 | `config/flashback/flashback.json` |
| 编辑器窗口布局 | `config/flashback/imgui.ini` |

关键帧、场景和许多编辑设置保存在独立的 `editor_states` 文件中，不是全部写进回放 ZIP。只复制 `replays/*.zip` 到另一台电脑，通常只能带走原始回放，不能保证带走已经做好的镜头工程。备份或迁移项目时，应同时保存整个 `flashback/replays` 和 `flashback/editor_states` 目录。

不要在游戏仍在录制、保存或导出时手动移动临时目录。

## 兼容性与使用边界

- Flashback 是 Fabric 客户端 MOD，服务器通常不需要安装。
- 多人服回放只包含客户端收到的内容；离开加载范围的区块和实体不一定存在于回放中。
- `0.41.1` 元数据明确拒绝 Iris 1.10.9 以前的版本。
- 源码包含对 Sodium、Iris、Axiom、Bobby、Distant Horizons 和 Simple Voice Chat 的针对性处理，但这不代表任意版本组合都保证兼容。
- Distant Horizons 集成要求其 API 主版本至少为 4；Bobby 和语音录制功能只有检测到对应模组后才出现。
- 最新 `0.41.1` 更新到 Minecraft 26.2，加入 Vulkan 支持和导出收尾进度提示；同时移除了不稳定的 Iris 第一人称手部渲染支持。
- 回放对游戏数据版本和注册表很敏感。录制后增删内容类 MOD，可能造成实体、方块或注册表不匹配。
- 录制语音聊天、玩家活动或服务器内容前，应遵守服务器规则、隐私约定和当地法律。

## 常见问题

### 为什么完成录制后没有直接得到 MP4？

Flashback 首先保存可编辑的回放 ZIP。打开回放、制作镜头后，再从“文件 → 导出视频”生成 MP4 或其他媒体文件。

### 为什么回放中看不到远处发生的事情？

客户端只能可靠记录自己加载和接收到的数据。Flashback 不是服务器全局录像系统；多人服中未发送给你的远处区块和实体通常无法事后补回。

### 为什么自己的第一人称镜头不够顺？

录制前提高“第一人称更新”频率，并让它至少接近计划导出的帧率。这个设置不能在录制结束后补救已经缺少的位置/角度采样。

### 为什么透明天空不能开启？

先在“视觉”窗口取消“渲染天空”，再打开导出窗口勾选“透明天空”。编码器和容器还必须真正支持透明通道。

### 为什么某种编码器没有出现在列表里？

Flashback 会检测容器、编码和本机编码器是否能实际配合工作。源码列出某个编码，不代表所有系统都会提供它。

### 为什么隐藏粒子后画面里还有粒子？

渲染过滤只阻止新的对应粒子生成，已经出现的粒子不会被立即清除。可以跳转时间、重新打开回放或等待旧粒子结束。

### 为什么把回放 ZIP 复制到另一台电脑后，关键帧不见了？

编辑工程单独保存在 `flashback/editor_states`。迁移时需要同时复制与回放 UUID 对应的编辑状态，最稳妥的做法是一起备份 `replays` 和 `editor_states` 两个目录。

### 为什么旧回放提示版本或注册表不匹配？

尽量恢复录制时使用的 Minecraft、Flashback、内容 MOD、资源包和数据包组合。不要用“能强行打开”推断回放一定完整；先备份文件，再检查实体、方块、声音和关键镜头。

### 导出很慢怎么办？

先关闭 SSAA、降低分辨率/帧率、暂时停用复杂光影，并把“虚拟渲染帧”保持为 0。虚拟帧主要用于依赖时间累积的着色器，会大幅增加导出时间。
