# Litematica 演示视频

`index.html` 默认从本目录读取 01—09 段视频。视频文件没有随文档源代码提交，以免把数 GB 的原始素材带进网站仓库；部署时可以：

- 将压缩后的章节视频放入本目录，并保持页面脚本中的文件名；或
- 把 `index.html` 中的 `mediaRoot` 和章节 `file` 改成对象存储、视频站或 B 站播放器地址。

默认文件名对应投影教程的 9 个章节：

```text
01投影介绍+mod安装说明.mp4
02投影的功能介绍+创建投影.mp4
03投影加载.mp4
04投影放置打印.mp4
05分层放置讲解.mp4
06创造模式直接放置.mp4
07投影编辑.mp4
08投影共享.mp4
09配置投影公共目录.mp4
```
