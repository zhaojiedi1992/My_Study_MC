02 / 05CHAT · IDENTITY

CHAT HEADS · 1.2.4

一眼认出
谁在说话

在聊天消息旁显示玩家皮肤头像，让多人聊天不再只靠昵称辨认。

  • 头像可放在整条聊天行前，或紧贴玩家名。
  • 支持 UUID、启发式检测和昵称别名纠正。
  • 纯客户端效果，服务器和其他玩家无需安装。
单独介绍
核心变化：聊天内容不变，只增加头像。Minecraft 26.1–26.2 · Fabric

04 / 05CHAT · PRIVACY

NO CHAT REPORTS · 2.20.1

减少消息的
账号签名

在服务器允许时发送未签名消息，降低聊天内容与账号举报证据直接关联的可能。

  • 客户端和服务端同时安装时，处理链路最完整。
  • 不会隐藏聊天，也不会阻止服务器保存日志。
  • 不能强行绕过服务器签名策略；Realms 不受保护。
单独介绍
核心变化：处理签名，不是加密聊天内容。Minecraft 26.2 · Fabric API

05 / 05SOCIAL · EMOTES

EMOTECRAFT · 3.4.0-B.BUILD.161

让角色用
动作表达

挥手、舞蹈或播放自定义动画，用玩家动作补充文字和语音交流。

  • “打开表情轮盘”默认绑定 B，与路径点冲突时可在按键设置中修改。
  • 在轮盘中左键选择动作；自定义动作放入 .minecraft/emotes。
  • 完整多人同步需要服务端和其他玩家客户端支持。
