02 / 02CORE · LIMITS

核心、安装与边界

先看服务器是否允许

客户端不再主动提供账号公钥，并在服务器允许时发送未签名消息。

核心作用减少可直接关联 Microsoft 账号的消息签名；客户端、服务端同时安装时最完整。
安装Fabric API 必需；Cloth Config、Mod Menu 仅用于配置入口。
边界不加密聊天、不阻止服务器日志，也不能强行绕过签名策略。

记住：它改变的是“签名”，不是聊天内容、服务器管理规则；Realms 不在保护范围内。
