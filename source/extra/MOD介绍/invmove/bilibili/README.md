## 推荐标题

打开背包还能继续走？Minecraft InvMove 实用 MOD 介绍

## 简介草稿

打开背包、箱子或其他界面时，角色只能站在原地？InvMove 把移动、跳跃和疾跑控制带进游戏界面，并允许按界面调整移动与背景遮罩策略。

本期用三段实录展示 InvMove 的核心用途：未安装时打开背包后无法移动；安装后可以在移动中打开背包，并在工作台界面内继续移动。最后简单说明 Fabric 26.2 的安装关系。

Modrinth：https://modrinth.com/mod/invmove

## PPT 章节（5 屏）

- 开场：打开背包，脚步不停
- 核心能力：界面内移动
- 未安装：打开背包合成界面后无法移动
- 安装后：移动中打开背包、工作台界面内继续移动
- 安装关系：Cloth Config、Fabric API、Mod Menu
