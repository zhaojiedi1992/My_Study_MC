WASD
核心能力 · 不只是按住 W

把移动控制带进游戏界面

InvMove 会在界面打开期间继续更新允许的移动按键，同时保留对输入框和特殊界面的保护。

W

边整理，边移动

打开背包、箱子等界面时继续前进、后退和转向，减少频繁关界面的操作。

↥

跳跃与疾跑

可以单独允许跳跃、疾跑、潜行和下坐骑；不是所有动作都必须一起开启。

◐

隐藏背景遮罩

对不会暂停游戏的界面隐藏暗色背景，更容易观察移动方向和周围环境。

⚙

逐界面控制

原版与模组界面可以分别设置；陌生界面也有默认处理策略。

重要保护：搜索框、铁砧命名等文字输入获得焦点时，可以自动暂停移动，避免输入 WASD 时角色乱跑。

安装前确认 · Fabric 26.2

三个文件关系，一次说清

本页以 InvMove 0.9.5+26.2-fabric Beta 为基线；其他 Minecraft 版本请选择对应构建。

REQUIRED

InvMove + Cloth Config

Cloth Config API 是必需依赖。缺少时无法正常加载配置支持。

OPTIONAL · FABRIC 26.2

Fabric API

当前 0.9.5 构建将相关按键 API 设为可选；未安装时不会添加“Toggle UI Movement”快捷键。

OPTIONAL · CONFIG ENTRY

Mod Menu

InvMove 本体可以运行；要在 Fabric 游戏内方便打开图形配置页，建议同时安装 Mod Menu。

兼容扩展REI、JEI、EMI 等额外兼容已移到 InvMoveCompats，需要时再安装。
部署边界纯客户端、服务器端不支持；公共服可能因反作弊策略产生风险。
