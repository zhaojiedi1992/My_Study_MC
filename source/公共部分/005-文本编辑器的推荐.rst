文本编辑器的推荐
==================================================

VSCODE
==================================================
VS Code（Visual Studio Code）是当前最流行的免费跨平台代码编辑器，支持 Windows、macOS 和 Linux。  
主要优点如下：

- **插件丰富**：支持 Java、Python、C/C++、Markdown、LaTeX、Minecraft 脚本等各种插件，满足不同开发和文档需求。
- **界面简洁**：界面现代，支持多标签、分屏、侧边栏、终端集成等，易于上手。
- **Git 集成**：内置 Git 工具，方便代码版本管理。
- **远程开发**：支持 SSH、WSL、容器等远程开发模式。
- **强大搜索与替换**：支持正则表达式、全局搜索、批量替换。
- **多语言支持**：支持中文界面，插件市场活跃。
- **社区活跃**：有大量教程、主题、插件和社区支持。

推荐插件
--------------------------------------------------
- Chinese (Simplified) Language Pack for Visual Studio Code
- Markdown All in One
- Prettier - Code formatter
- GitLens
- Remote - SSH
- Bracket Pair Colorizer 2
- Minecraft Development (mcdev)
- YAML、JSON、CSV、LaTeX 等格式支持插件

其他推荐编辑器
==================================================
- **Sublime Text**：轻量、启动快、插件丰富，适合简单编辑和批量处理。
- **Notepad++**：Windows 下的经典文本编辑器，体积小巧，适合快速查看和简单编辑。
- **JetBrains 系列（如 IntelliJ IDEA、PyCharm）**：适合大型项目和专业开发，功能强大但资源占用较高。
- **Vim/Neovim**：命令行下的高效编辑器，适合熟悉快捷键的用户。

总结
==================================================
- 日常开发、文档编辑、配置文件维护，首选 VS Code。
- 轻量编辑可用 Sublime Text、Notepad++。
- 专业开发或大型项目可考虑 JetBrains 系列。
- 熟悉命令行的用户可用 Vim/Neovim。


VSCODE REMOTE使用
==================================================
VS Code Remote 是 VS Code 的一项强大功能，允许用户通过 SSH 连接到远程服务器进行开发。  
这对于 Minecraft 服务器管理和开发非常有用，可以直接在服务器上编辑配置文件、脚本和代码，而无需下载到本地。

安装 VS Code Remote
--------------------------------------------------
1. 打开 VS Code，进入插件市场（Extensions）。
2. 搜索并安装 "Remote - SSH" 插件。
3. 安装完成后，重启 VS Code。
4. 在左侧活动栏中，点击绿色的 "><" 图标，选择 "Remote-SSH: Connect to Host..."。
5. 输入远程服务器的 SSH 地址（如 `user@your-server-ip`），并按 Enter。
6. 如果是第一次连接，会提示输入 SSH 密码或密钥。
7. 连接成功后，VS Code 会在远程服务器上打开一个新的窗口
8. 现在你可以在远程服务器上浏览文件、编辑代码、运行终端命令等。
9. 可以通过左侧的资源管理器浏览服务器上的文件系统，双击文件即可在编辑器中打开。
10. 可以使用内置终端（Terminal）直接在服务器上运行命令。
11. 可以安装和使用各种插件，增强远程开发体验。
12. 可以通过 "Remote Explorer" 视图管理多个远程连接。
13. 可以在远程服务器上运行调试会话，支持多种编程语言。
