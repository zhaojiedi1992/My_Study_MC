# 告别手搓建筑！Minecraft 投影模组 01—09 B 站发布包

## 直接使用

- 成片：`成片/投影模组从入门到共享_01-09_B站发布版_吸睛版.mp4`
- 外挂字幕：`字幕/投影教程_中文字幕.srt`
- B 站封面（推荐 4:3）：`素材/B站封面_投影模组教程_4x3.jpg`
- 标题、简介和标签：`发布文案/标题_简介_标签.txt`
- 可直接粘贴到 B 站简介的章节：`发布文案/B站章节格式.txt`

成片保留原视频的 2880×1800、60 fps 画质，内嵌中文字幕和 9 个章节标记；外部 SRT 也已单独提供，便于在 B 站后台重新上传或修改字幕。

## 处理说明

01—08 按文件编号顺序拼接。原始第 09 段没有可用音轨，发布版为它补了一条与画面等长的静音 AAC 音轨，因此最后一段不会出现播放器音轨中断。

`原始视频/` 是从用户指定视频目录复制进本项目的副本，源文件未被修改。
