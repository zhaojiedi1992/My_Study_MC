# Tweakeroo 26.2 PPT 内容设计：四个实用能力

> 这份 Markdown 是后续 `index.html` 的内容底稿，不是最终 PPT。成品不做功能大全，只讲四个容易理解、能够直接改善游玩体验的能力。

## 0. 展示目标

用尽量少的页面回答三个问题：

1. Tweakeroo 能解决哪些常见操作问题？
2. 这四项能力怎样启用，哪些参数值得调整？
3. 哪些功能在多人服务器使用前必须先确认规则？

最终只保留以下四项核心内容：

1. **灵魂出窍**：给观察视角配置一个顺手的快捷键。
2. **快速点击**：把快速左键和快速右键合并讲成“连点器”能力。
3. **自动补货**：手中物品不足时从背包继续补充。
4. **Gamma 亮度修改**：提高矿洞等昏暗环境的可见度。

## 2. 一句话定位

**Tweakeroo 是一组可独立开关、可绑定快捷键的客户端操作优化；本期不做功能大全，只选四项真正容易用起来的能力。**

观众看完应记住：

- 先打开配置菜单，再给经常切换的功能绑定快捷键。
- 快速点击、自动补货都可以继续调整参数，不能只打开开关就结束。
- Gamma 只改变客户端画面亮度，不会改变世界真实光照。
- 多人服务器是否允许，以服务器规则为准。

## 3. 建议的 8 页 PPT 结构

### 第 1 页｜封面：四个让操作更顺手的小改动

- 主标题：`Tweakeroo`
- 副标题：`灵魂出窍 · 连点器 · 自动补货 · Gamma 亮度`
- 一句话：`不背功能表，只解决四个常见问题`
- 主视觉：矿洞环境中的玩家，画面同时具备明暗层次和可观察的远处结构。

### 第 2 页｜能力总览：本期只讲这四项

使用四张能力卡：

| 能力 | 解决的问题 | 推荐展示方式 |
| --- | --- | --- |
| 灵魂出窍 | 想换角度观察，但不想移动玩家本体 | 玩家位置与镜头位置对比 |
| 快速点击 | 某些动作需要反复点击左右键 | 设置界面与实际触发过程 |
| 自动补货 | 手中一组物品用完后动作被打断 | 补货前、触发时、补货后 |
| Gamma 亮度 | 下矿时环境过暗、细节看不清 | 同一矿洞机位明暗对比 |

这一页不出现其他能力入口，也不放完整功能列表。

### 第 3 页｜灵魂出窍：先给镜头绑定快捷键

核心说明：

- **灵魂出窍**（Free Camera / `tweakFreeCamera`）让镜头离开玩家本体进行观察。
- 玩家仍停留在启用功能时的位置；它不是传送，也不会让玩家实体跟随镜头移动。
- 这项能力需要频繁开关，建议配置一个不会与移动、背包和截图操作冲突的快捷键。
- 当前本地示例绑定为 `Left Alt + C`；它只是个人配置示例，不写成模组默认键位。
- 镜头只能观察客户端已经加载的内容，不能把未加载区域当成已经存在的画面。

实机演示顺序：

1. 在配置菜单中找到 `tweakFreeCamera`。
2. 展示当前快捷键，并说明可以按个人习惯修改。
3. 玩家站在固定位置开启功能。
4. 镜头移动到建筑上方或机器侧面。
5. 关闭功能，视角回到玩家本体。

页面主句：**玩家留在原地，镜头出去观察。**

### 第 4 页｜快速点击：左右键合并成一个连点器能力

核心说明：

- **快速左键**（`tweakFastLeftClick`）和**快速右键**（`tweakFastRightClick`）放在同一页介绍。
- 左右键分别启用、分别绑定快捷键，也可以分别设置单次触发的点击次数。
- 当前本地参数中，左右键点击次数均为 `10`；两项目前都未启用，也没有绑定快捷键。
- 快速右键还可以按手持物品和目标方块设置黑白名单，减少误触。
- 页面不继续展开持续点击、周期性点击和周期性长按；这些不是本期重点。

实机演示顺序：

1. 并排展示快速左键和快速右键两个开关。
2. 给其中一个功能绑定测试快捷键。
3. 展示点击次数参数和限制名单入口。
4. 在单人测试场景中演示普通点击与快速点击的差别。
5. 演示结束后关闭功能，避免影响后续操作。

风险提示必须与功能说明同时出现：

> 连点会改变客户端发送操作的节奏；多人服务器可能限制点击频率，使用前应先确认规则。

### 第 5 页｜自动补货：一组用完，继续从背包补

核心说明：

- **自动补货**（Hand Restock / `tweakHandRestock`）在主手或副手物品不足时，从背包换入同类物品。
- **提前补货**（`handRestockPre`）允许在物品尚未完全用完时先补充，减少动作中断。
- **补货阈值**（`handRestockPreThreshold`）决定剩余数量降到多少时触发提前补货。
- **名单类型**（`handRestockListType`）可限制哪些物品参与自动补货。

当前本地配置：

- `tweakHandRestock = true`
- `handRestockPre = true`
- `handRestockPreThreshold = 6`
- `handRestockListType = none`

实机演示使用固定机位，记录：

1. 手中物品即将降到阈值。
2. 自动补货触发。
3. 快捷栏物品数量恢复，动作没有被打断。

页面主句：**补货的价值不是“自动整理”，而是让正在进行的动作少停一次。**

### 第 6 页｜Gamma 亮度：下矿时看得更清楚

核心说明：

- **伽马值修改**（Gamma Override / `tweakGammaOverride`）覆盖客户端画面的 Gamma 值，提高昏暗区域的可见度。
- 当前本地配置已经启用，`gammaOverrideValue = 16.0`。
- 最适合用同一矿洞、同一视角、同一时间的开关前后画面对比。
- Gamma 只影响客户端渲染出来的明暗，不会放置光源，也不会改变方块光照、刷怪条件或服务器世界状态。
- 亮度过高会压低画面对比度；页面只说明根据显示器和环境适量调整，不把 `16.0` 宣传成通用推荐值。

页面主句：**它让你看清矿洞，不会把矿洞真的照亮。**

### 第 7 页｜怎样开始：开关、快捷键、参数

统一操作流程：

1. 按 `X + C` 打开 Tweakeroo 配置菜单。
2. 在功能开关中启用需要的能力。
3. 对灵魂出窍和快速点击配置顺手且不冲突的快捷键。
4. 调整连点次数、补货阈值或 Gamma 值。
5. 先在单人世界测试，再决定是否用于多人服务器。

本地实时配置仅用于截图和验证，不作为所有玩家都应照抄的模板：

| 功能 | 当前开关 | 当前快捷键或参数 |
| --- | --- | --- |
| 灵魂出窍 | 关闭 | `Left Alt + C` |
| 快速左键 | 关闭 | 未绑定；点击次数 `10` |
| 快速右键 | 关闭 | 未绑定；点击次数 `10` |
| 自动补货 | 开启 | 提前补货；阈值 `6` |
| Gamma 亮度 | 开启 | Gamma 值 `16.0` |

截图时必须以实时配置文件重新核对，避免游戏内修改后表格过期。

### 第 8 页｜多人边界与安装

必须保留：

- Modrinth 将 Tweakeroo 标为客户端必需、服务器端不支持。
- 客户端模组不等于服务器一定允许；项目说明也提醒部分功能可能被视为过强或作弊。
- 快速点击会改变点击节奏，自动补货会产生槽位操作，灵魂出窍也可能受到服务器规则限制。
- 结论：**先询问服主或管理员；不确定时只在单人世界或明确允许的私服使用。**
- 安装路径：创建 Minecraft `26.2` Fabric 实例 → 安装 Tweakeroo `26.2-0.29.2` → 安装匹配的 MaLiLib `0.29.2` 线 → 启动后按 `X + C` 打开配置菜单。
- 项目信息：作者 `masa`，贡献者 `Sakura-Ryoko`，许可证 `LGPLv3`。

收尾句：**先挑一个真正需要的功能，再把快捷键和参数调成自己的习惯。**

## 4. 内容取舍规则

成品遵守以下范围：

- 只讲灵魂出窍、快速点击、自动补货和 Gamma 亮度。
- 已经由其他专题承担的能力不在正文、弹窗或附录重复。
- 方块放置、信息显示、库存滚动等能力不进入本期内容。
- 不用“还有几十项功能”扩充页面，也不展示完整配置菜单清单。
- 小众快捷键、兼容项、修复项、源码实现和服务端规避方法全部省略。
- 截图中即使出现无关配置项，也要通过裁切、景深或标注控制，避免抢占注意力。

## 5. 实机截图需求

建议统一使用 **2560×1440 或 3840×2160、16:9、无 F3、无聊天窗口、无鼠标光标**。所有对比图必须保持相同机位和画面设置。

| 文件名（建议） | 对应页面 | 需要拍什么 | 是否必须 |
| --- | --- | --- | --- |
| `cover-mining.webp` | 1 | 矿洞中的玩家与远处结构，保留明显明暗层次 | 建议 |
| `four-capabilities.webp` | 2 | 四项能力的统一视觉卡片或四格场景 | 建议 |
| `free-camera-player.webp` | 3 | 玩家留在原地、镜头移动到其他观察角度 | 必须 |
| `free-camera-hotkey.webp` | 3 | `tweakFreeCamera` 的快捷键配置 | 必须 |
| `fast-click-settings.webp` | 4 | 左右键开关、快捷键、点击次数和限制入口 | 必须 |
| `hand-restock.webp` | 5 | 补货触发前后对比 | 必须 |
| `gamma-mining.webp` | 6 | 同一矿洞机位的 Gamma 开关前后对比 | 必须 |
| `tweakeroo-config.webp` | 7 | `X + C` 打开的 26.2 配置菜单 | 必须 |

动态行为优先准备触发前、触发时、触发后三帧；后续如果补录视频，可以在相同页面区域替换为短视频演示。

### 截图时一并记录

- Minecraft、Fabric Loader、Tweakeroo 和 MaLiLib 版本。
- 展示的快捷键是否为个人配置。
- 连点次数、补货阈值和 Gamma 值。
- 是否在单人世界拍摄。
- 如果截图不是来自 26.2，不得直接进入成品。

## 6. 页面交互与版式约定

- 延续现有 MOD 演示页的深色 Minecraft 场景、彩色玻璃卡片、圆点导航和键盘左右翻页。
