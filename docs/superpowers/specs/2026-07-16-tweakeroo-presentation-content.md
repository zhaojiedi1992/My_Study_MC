# Tweakeroo 26.2 PC 演示 PPT：五个实用能力

> 这份 Markdown 是 `source/MOD介绍/tweakeroo/index.html` 的内容与交互规格。成品将直接用于 PC 浏览器演示，并作为后续视频录制的画面来源。

## 0. 展示目标

成品不做功能大全，只讲五个容易理解、能够直接改善游玩体验的能力，并大量使用用户提供的真实游戏截图。

五项能力固定按以下顺序出现：

1. **灵魂出窍**：玩家留在原地，镜头出去观察。
2. **自动切换鞘翅与胸甲**：飞行与落地装备切换更顺手。
3. **自动补货**：手中物品不足时从背包继续补充。
4. **快速点击**：把快速左键和快速右键合并讲成“连点器”能力。
5. **Gamma 亮度修改**：提高矿洞等昏暗环境的可见度。

观众看完应能回答：

- 这五项能力各自解决什么问题？
- 哪些功能值得绑定快捷键，哪些参数值得调整？
- 哪些画面变化只是客户端效果？
- 哪些功能在多人服务器使用前必须先确认规则？

**Tweakeroo 是一组可以独立开关、绑定快捷键和调整参数的客户端操作优化；本期只用五个真实场景说明它怎样让游戏更顺手。**

- 灵魂出窍必须是第一个正式介绍的功能。

## 3. 8 页 PPT 结构

### 第 1 页｜封面：五个让操作更顺手的小改动

- 主标题：`Tweakeroo`
- 副标题：`观察 · 飞行 · 续航 · 连点 · 亮度`
- 一句话：`不背功能表，只解决五个常见问题`
- 主视觉使用 `开启灵魂出窍.png`，让玩家本体成为封面视觉锚点。
- 五项能力只作为短标签出现，不抢先解释细节。

### 第 2 页｜01 灵魂出窍：先给镜头绑定快捷键

核心说明：

- **灵魂出窍**（Free Camera / `tweakFreeCamera`）让镜头离开玩家本体进行观察。
- 玩家仍停留在启用功能时的位置；它不是传送，也不会让玩家实体跟随镜头移动。
- 这项能力需要频繁开关，建议配置一个不会与移动、背包和截图操作冲突的快捷键。
- 当前本地示例为 `Left Alt + C`，不是模组默认键位。
- 镜头只能观察客户端已经加载的内容。

图片与交互：

- “配置”状态使用 `灵魂出窍配置.png`，默认裁切到“灵魂出窍”开关和快捷键区域。
- “效果”状态使用 `开启灵魂出窍.png`，完整展示远处镜头与留在原地的玩家。
- 页面进入时先展示效果图，再通过按钮切换到配置图。
- 提供“聚焦快捷键”按钮，将配置图平滑放大到当前键位所在行；再次点击恢复。

页面主句：**玩家留在原地，镜头出去观察。**

### 第 3 页｜02 自动鞘翅：起飞自动换，落地一键换回

核心说明：

- **自动切换鞘翅**（`tweakAutoSwitchElytra`）已经在当前本地配置中启用。
- 当前还启用了自动切换火箭，但本页只把它作为鞘翅流程的补充标签，不单独展开。
- **切换鞘翅与胸甲**（`swapElytraChestplate`）用于手动交换当前装备。
- 当前个人快捷键为 `Left Alt + W`，不是模组默认键位。
- 页面重点是“自动切换开关”和“手动交换快捷键”两个配置点。

图片与交互：

- 使用 `自动鞘翅配置.png` 作为整页主图。
- 默认完整显示配置场景；依次提供“自动切换”和“胸甲快捷键”两个聚焦按钮。
- 点击按钮时，图片平滑放大并移动到对应配置行，同时在图外显示一句解释。
- 不伪造缺失的飞行效果图；配置图已经足以证明当前设置。

页面主句：**自动负责时机，快捷键负责临时决定。**

### 第 4 页｜03 自动补货：一组用完，继续从背包补

核心说明：

- **自动补货**（Hand Restock / `tweakHandRestock`）在主手或副手物品不足时，从背包换入同类物品。
- **提前补货**（`handRestockPre`）允许在物品尚未完全用完时先补充。
- **补货阈值**（`handRestockPreThreshold`）决定剩余数量降到多少时触发。
- 当前本地配置为：自动补货开启、提前补货开启、阈值 `6`、名单类型 `none`。

图片与交互：

1. “配置”：`自动补货.png`，聚焦提前补货、阈值和名单。
2. “到达阈值”：`使用到阈值了.png`，聚焦快捷栏中的剩余数量 `7`。
3. “补货完成”：`自动补货完毕.png`，聚焦快捷栏恢复到 `19`。

三张图通过阶段按钮切换。切换时使用轻微镜头推进和淡入，不自动轮播，方便视频录制时控制节奏。

页面主句：**自动补货让正在进行的动作少停一次。**

### 第 5 页｜04 快速点击：左右键合并成一个连点器

核心说明：

- **快速左键**（`tweakFastLeftClick`）与**快速右键**（`tweakFastRightClick`）放在同一页。
- 左右键分别启用、分别绑定快捷键，也可以分别调整点击次数。
- 当前本地参数中左右键点击次数均为 `10`；两项目前都未启用，也没有绑定快捷键。
- 快速右键还可以使用物品和目标方块名单减少误触。
- 持续点击、周期性点击和周期性长按不在本期展开。

图片与交互：

- 使用 `连点配置.png` 作为主图。
- 页面通过“左键”和“右键”两个按钮分别聚焦对应行。
- 聚焦时在图片旁显示“独立开关、独立快捷键、独立参数”的三点提示。
- 风险提示必须始终可见，不能藏在弹窗中。

风险提示：

> 连点会改变客户端发送操作的节奏；多人服务器可能限制点击频率，使用前应先确认规则。

### 第 6 页｜05 Gamma 亮度：下矿时看得更清楚

核心说明：

- **伽马值修改**（Gamma Override / `tweakGammaOverride`）覆盖客户端画面 Gamma，提高昏暗区域的可见度。
- 当前本地配置已经启用，`gammaOverrideValue = 16.0`。
- Gamma 只影响客户端渲染明暗，不会放置光源，也不会改变方块光照、刷怪条件或服务器世界状态。
- `16.0` 只是当前个人设置，不作为通用推荐值。

图片与交互：

- “配置”状态：`gama亮度修改.png`。
- “关闭”状态：`关闭ganma的.png`。
- “开启”状态：`启用ganam的.png`。
- 默认先显示关闭效果，再切换至开启效果，形成强烈的同机位对比。
- 支持“对比”按钮在关闭、开启之间快速切换；图片始终占页面主体。

页面主句：**它让你看清矿洞，不会把矿洞真的照亮。**

### 第 7 页｜快速上手：开关、快捷键、参数

统一流程：

1. 按 `X + C` 打开 Tweakeroo 配置菜单。
2. 在功能开关中启用需要的能力。
3. 为灵魂出窍、胸甲交换和快速点击配置不冲突的快捷键。
4. 调整补货阈值、连点次数或 Gamma 值。
5. 先在单人世界测试，再决定是否用于多人服务器。

当前本地配置仅用于截图与验证：

| 功能 | 当前开关 | 当前快捷键或参数 |
| --- | --- | --- |
| 灵魂出窍 | 关闭 | `Left Alt + C` |
| 自动切换鞘翅 | 开启 | 胸甲交换 `Left Alt + W` |
| 自动补货 | 开启 | 提前补货；阈值 `6` |
| 快速左键 | 关闭 | 未绑定；点击次数 `10` |
| 快速右键 | 关闭 | 未绑定；点击次数 `10` |
| Gamma 亮度 | 开启 | Gamma 值 `16.0` |

页面使用五步流程和五项能力索引，不新增截图。

### 第 8 页｜安装与多人边界

必须保留：

- Modrinth 将 Tweakeroo 标为客户端必需、服务器端不支持。
- 客户端模组不等于服务器一定允许；项目说明也提醒部分功能可能被视为过强或作弊。
- 快速点击会改变点击节奏，自动补货会产生槽位操作，灵魂出窍也可能受到服务器规则限制。
- 结论：**先询问服主或管理员；不确定时只在单人世界或明确允许的私服使用。**
- 安装路径：Minecraft `26.2` Fabric 实例 → Tweakeroo `26.2-0.29.2` → 匹配的 MaLiLib `0.29.2` 线 → `X + C` 打开配置。
- 项目信息：作者 `masa`，贡献者 `Sakura-Ryoko`，许可证 `LGPLv3`。

收尾句：**先挑一个真正需要的功能，再把快捷键和参数调成自己的习惯。**

## 5. PC 版式与图片表现

- 只支持 PC 浏览器，不设计移动端布局。
- 目标画布为 `1920×1080`、16:9；最低验收视口为 `1280×720`。
- 页面占满浏览器视口，正文不出现纵向滚动条。
- 功能页图片区域占可用内容宽度约 68%–74%，文字说明位于右侧。
- 配置截图优先显示有效配置区域；背景和无关菜单通过 `object-position`、裁切与暗角弱化。
- 效果截图尽可能完整展示，避免把玩家、快捷栏数量或 Gamma 对比主体裁掉。
- 使用本地系统字体，页面完全离线可用，不加载远程字体和资源。

视觉方向：

- 深蓝黑背景、青蓝主色、橙金快捷键强调色。
- 玻璃卡片只承载说明，不遮挡主要图片。
- 图片边框、焦点框和状态标签采用 Minecraft UI 的硬朗像素感，但不复制游戏菜单。
- 封面与功能页保持统一，不照搬仓库中已有演示页的具体版式。

## 6. 动画与交互

必须支持：

- 键盘 `←`、`→`、`PageUp`、`PageDown`、空格翻页。
- 底部圆点跳转和页面内状态按钮。
- 幻灯片进入时使用短距离上移、透明度和轻微缩放动画。
- 效果图进入时使用轻微镜头推进；配置图的局部放大由用户按钮触发。
- 放大动画只改变图片 `transform` 和裁切位置，不改变页面结构，避免视频画面跳动。
- 所有多状态图片默认不自动轮播，保证视频录制节奏可控。
- `Esc` 可以退出局部放大或回到当前页默认状态。

无障碍与操作：

- 非当前页使用 `inert` 与 `aria-hidden`，避免隐藏按钮仍可获得焦点。
- 所有按钮有可见焦点样式和明确的 `aria-label`。
- 支持 `prefers-reduced-motion`，但普通模式保留完整放大与切换动画。

## 7. 视频制作接口

`index.html` 必须支持通过 URL 固定录制状态：

- `?slide=2`：直接打开指定页。
- `?slide=2&state=config`：打开指定页的指定图片状态。
- `?slide=3&state=chestplate`：直接聚焦胸甲快捷键。
- `?slide=4&state=done`：直接打开补货完成画面。
- `?slide=6&state=on`：直接打开 Gamma 开启画面。
- `?export=1`：隐藏导航和操作提示、关闭过渡动画，输出稳定画面。

实现要求：

- 页码与状态改变时同步更新查询参数，但不刷新页面。
- 刷新后能恢复相同页码和图片状态。
- 导出模式必须保持 16:9 构图，不能因隐藏导航导致主体位置变化。
- 所有录制状态使用同一份 DOM，不额外复制“视频专用幻灯片”。
